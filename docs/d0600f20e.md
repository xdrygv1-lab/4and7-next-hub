# 사내근로복지기금 (기본형, 법인·중소기업)

> **한눈에** 회사가 이익 일부를 출연해 회사와 별개인 기금법인을 만들고, 그 기금으로 직원 복지를 지급하는 제도입니다. "회사는 덜 내고, 직원은 더 받는" 구조라 거의 모든 절세 컨설팅의 기반 인프라가 됩니다. 인건비 부담과 직원 유지가 고민인 중소 법인에 씁니다.

## 이런 업체에 맞아요
아래 중 **두 가지 이상**이면 검토할 만합니다.
- 가지급금이 계속 쌓인다 (실제 직원에게 나간 돈인데 증빙이 안 되는 부분)
- 미처분이익잉여금이 매년 늘어난다
- 가업승계 세금이 부담된다
- 핵심 직원이 나갈까 걱정된다
- 임금을 올려도 직원이 가져가는 게 적다

| 효과가 큰 경우 | 효과가 제한적인 경우 |
|---|---|
| 상시근로자 **5인 이상** | 5인 미만 |
| 연봉 **5천만 원** 이상 직원 여럿, 실수령 약정 인력 | 급여 수준이 전반적으로 낮음 |
| 상여·복지포인트 등 복지성 지급이 이미 있음 | 이익이 불규칙 |
| 연장·야간·휴일 근로가 상시 | 대표가 자금 회수를 전제로 생각함 |

대표가 먼저 "인건비 좀 어떻게 안 될까요?"라고 꺼내는 경우가 많습니다. 대형 사업장보다 유연한 중소 규모에서 잘 접목됩니다.

## 대표가 느끼는 고민
- 급여로 주면 4대보험·소득세로 대략 **30%** 안팎이 빠진다
- 판례 흐름상 정기상여금은 통상임금에 들어가고, 복지포인트는 근로소득으로 본다
- 임금은 한 번 올리면 못 내린다
- 이미 쓰는 복지비가 세무조사·공단 조사에서 문제 될까 걱정된다

## 해결 방향
1. 회사가 이익 일부를 기금법인에 출연 (직전 사업연도 세전 순이익의 **5%** 기준, 의무 아님)
2. 기금법인이 기본재산으로 보유·운용
3. 정관과 협의회 의결에 따라 직원에게 복지 지급 (임금이 아니므로 4대보험 부과 대상 아님)
4. 당해 사용 한도 관리: 원칙 **50%**, 중소기업·선택적 복지는 **80%**
5. 설립 절차: 준비위원회, 정관 작성, 고용노동부 인가, 인가 후 **3주** 이내 설립등기

| 지급 방식 | 회사 지출 | 직원 실수령 |
|---|---|---|
| 급여로 지급 | 100 | 약 70 |
| 기금으로 지급 | 100 | 100 (당해 사용한도 내) |

| 쓸 수 있는 복지 (예) | 쓸 수 없는 지급 (예) |
|---|---|
| 무주택자 주택구입·임차 지원, 생활안정자금 대부 | 전 직원에게 일률적으로 주는 체력단련비·휴가비·유류비 |
| 근로자·자녀 장학금, 자녀 학원비 | 4대보험 사용자 부담분 지원 |
| 경조비, 명절선물, 생일·결혼기념일 축하금 | 업무 관련 수강료·출장비, 통근버스 |
| 근로자·가족 의료비, 건강진단비 | 회사가 줘야 할 퇴직금·퇴직위로금 |
| 체육·문화활동 실비, 직장인 단체보험 가입 지원 | 우수사원 포상금, 업무 관련 격려금 |

쓰지 못하고 쌓인 적립금은 운용수익 활용, 복지시설·회원권 취득, 대부사업 등으로 해소합니다 (회원권을 대표 전용으로 쓰면 즉시 문제).

세무 처리(비용처리·손금·익금 등)는 세무사 검토 사항입니다.

## 첫 미팅에서 이렇게 물어보세요
- "대표님, 세금과 4대보험이 많이 나가시지 않나요?"
- "올해 명절상여나 성과급이 나가나요? 통상임금에 들어가면 연장수당·퇴직금이 같이 오르는 건 체크해 보셨어요?"
- "직원분들 연봉 올려주실 때 실제로 손에 쥐는 건 얼마나 늘던가요?"
- "핵심 인력을 붙잡을 카드가 급여 말고 있으세요?"
- "다섯 가지 고민 중 어느 쪽이 제일 크게 와닿으세요?" (이 답이 2차 보고서 목차가 됩니다)

## 이렇게 말해 보세요
> "대표님, 세금을 안 내게 하는 마법은 아닙니다. 효과와 단점까지 다 말씀드릴 테니 판단은 대표님이 하시면 됩니다."

> "효과가 없다고 나오면 그대로 말씀드립니다. 단정이 아니라 추정치로 보여드립니다."

> "설립은 한 달이면 끝나지만 운영은 계속됩니다. 저희가 2년 동안 옆에서 함께하겠습니다."

⚠ 클로징은 진행 여부, 출연 규모, 복지 항목, 착수 시점 네 가지로 좁힙니다.

## 자주 나오는 반론
| 반론 | 대응 |
|---|---|
| 우리 세무사님은 안 된다던데요. | 임금성 지적은 맞는 말씀입니다. 근거 조문을 정리해 세무사님께 보내드리거나 직접 통화드리겠습니다. |
| 세법이 바뀌면요? | 되돌릴 가능성은 낮다고 보지만 100% 장담은 못 합니다. 그때까지 받은 절감 효과는 남습니다. |
| 돈이 묶이는 게 부담스럽습니다. | 매년 하지 않아도 됩니다. 이익 좋은 해에 하고 어려운 해엔 쉬면 됩니다. 켜고 끌 수 있는 게 장점입니다. |
| 직원들이 퇴직금 줄어든다고 싫어할 텐데요. | 퇴직금은 종전 급여 기준으로 산정한다고 규정하거나, 절감분을 반영해 지급액을 **10~15%** 올립니다. |
| 직원이 몇 명 안 되는데 되나요? | 협의회·이사·감사 구성 때문에 실무상 **5명** 안팎이 필요합니다. 빠듯하면 관할 지청에 미리 확인합니다. |
| 설립비 싸게 해 주는 곳도 있던데요. | 설립보다 운영이 본체입니다. 설립만 하는 계약은 하지 않습니다. |
| 나중에 대표인 제가 좀 쓰면 안 되나요? | 안 됩니다. 정관 수혜자에 대표가 들어가 있는지가 전수조사 첫 확인 항목입니다. 대표님을 지키는 일입니다. |
| 보험 얘기하러 오신 거죠? | 오늘은 기금 이야기만 드립니다. 무언가 해 드릴 테니 보험 들어 달라는 방식은 하지 않습니다. |

## 연결되는 상품
PC 단계에서만: 기금과 별개로 "대표님 유고 시 회사와 가족에게 얼마가 필요한가"를 따로 계산해 보장성 보험 제안 (기금의 대가로 보험을 요구하지 않음).

## 꼭 확인할 것
- [ ] 금지선: 대표자 수혜, 대표·특수관계인 대부, 페이백, 임원 편중, 기존 복지·임금 감축 후 대체
- [ ] 출연금은 회수 불가 (회사 재산도 대표 재산도 아님), 감당 가능한 규모만 출연
- [ ] 정관 변경은 노동부 인가 사항, 매년 결산서·운영상황보고서 제출과 서류 **5년** 보관
- [ ] 대부 사업은 저리, 한도·우선순위를 정관에 명시
- [ ] 기금 재원으로 보험 가입 가능 여부, 최소 인원, 지원금 요건 등은 확정 답변 금지 (확인 필요)
- [ ] 첫 요청 자료: 최근 3개년 재무제표, 1년치 월별 급여대장, 급여·상여·복리후생비 계정별원장, 현행 복지제도 목록
