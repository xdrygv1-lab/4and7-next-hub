## 3. 이번에 고도화한 것 (26.10.04)
1. **생성기: 재무제표 붙여넣기 → 자동 입력.** 매출·순이익·자본총계·이익잉여금·현금·가지급금(주임종 채권)·토지·건물을 읽고 신호를 자동 체크 (가지급금 0.5억↑, 잉여금 5억↑, 부동산 50%↑, 손실). 시험: 법인 재무상태표 텍스트로 정상 인식 확인.
2. **생성기 ↔ 시뮬레이터 연결.** 진단 결과에서 "경정기 시뮬레이터에서 55세 남 바로 보기" 링크. 시뮬레이터는 `?age=55&sex=남&uw=일반&bud=500` 형태로 조건을 받음.
3. **PS리스트 신호 16개 + 컨셉 6개 추가** (세무리스크 정리, 구조 셋팅, 잉여금 출구전략, 가지급금 해소, 밸류업, 가장·사업 보장). 진단 카드에 접근명분과 PS 유사 사례 결과 표시. 위험 사례는 제외하고 경고.
4. **시뮬레이터 보험료 기준 보기 보강** (월 보험료 프리셋, 기준연도 누적 납입·해지환급금 열).
5. **concept-check 스킬 신규.** 녹음을 이 PC에서만 녹취 → 신호·채점·PC 준비. 시연 녹취로 시험 완료.
6. **세무 문구 정정 체계** ((내부 자료)가 원문보다 우선).
7. **원클릭 갱신 스크립트** `build_all.py`.

## 4. 목표 흐름: "녹음이나 재무자료를 넣으면 컨셉이 나온다"
```
[입력]                         [처리]                                  [출력]
재무제표(PDF·엑셀·붙여넣기) ─┐
가결산 자료               ─┼→ 신호 추출 → 컨셉 진단(54개 카드·PS표) ─→ 컨셉 1~3순위 + 근거
AP 녹음(m4a)             ─┤      ↑ 로컬 녹취(고객정보 외부 전송 X)    ─→ AP 채점 + 고칠 점
상황카드(직접 입력)        ─┘      ↑ 정정사항·세무메모 우선 적용        ─→ AP 스크립트(첫 미팅 전)
                                                                    ─→ PC 준비안 + 시뮬레이터 링크
                                                                    ─→ 사례 DB 익명 1줄 (축적)
```
- **AP 전:** 재무자료 + 상황카드 → 컨셉 진단 → AP 스크립트 (생성기 / ap-script-generator)
- **AP 후:** AP 녹음 → 녹취 → 대표 발언에서 숫자·니즈 추출 → 채점 → PC 준비안 (concept-check)
- **PC 후 (다음 단계):** PC 녹음 → 반론 분석 → 클로징 전략 → 결과 기록
- **축적:** 매 건의 익명 요약이 쌓이면 ① 재정심사 승인 패턴 ② 업종·나이별 성공 컨셉 ③ 우수 화법이 데이터로 남음 → 진단 가중치를 사람이 아니라 결과로 조정

## 5. 자동화 로드맵 (신중하게)

### 원칙
1. **고객정보는 밖으로 내보내지 않는다.** 녹음은 로컬 녹취, 지식베이스·사례 DB에는 익명화한 것만. 실명·주민번호·연락처·계좌 금지. 고객 녹음은 **동의를 받은 것만** (동의 문구 표준안 필요).
2. **사람이 확인하는 단계를 없애지 않는다.** 세무 판단, 상품 금액, 고객에게 나가는 문서는 항상 세무사·지점장 확인 후. 도구는 "초안 + 근거"까지.
3. **근거를 보여준다.** 모든 진단에 근거를 달아야 신뢰가 생기고, 틀렸을 때 바로 고칠 수 있음 (10/02 "크레드는 블랙박스라 안 쓴다").
4. **데이터 갱신은 한 곳에서.** 상품 데이터는 (내부 자료), 컨셉·화법은 (내부 자료), 정정은 `00_정정사항.md`. `build_all.py` 한 번으로 모든 도구에 반영.
5. **규제 리스크.** 보험료·환급률 수치는 내부 검토용, 고객용 자료는 회사 심의 범위 확인. 변액 수익률 안내는 금소법 광고 규제 검토. 보험을 컨설팅 대가로 요구하지 않음.
6. **AI 툴에 묶이지 않는다.** 지식은 md·csv로 보관 → Claude 외 다른 도구로도 옮길 수 있음 (10/02 "범용적으로").
