# 01. 보험용어 사전 (지점원용, 120개)

- 기준일: 2026-10-04
- 읽는 법: 용어마다 **쉬운 설명(1~2줄) / 예시(1줄) / 출처** 순서입니다. 예시의 숫자는 2026년 9~10월 자료 기준이며, 고객에게 보여줄 숫자는 반드시 실제 가입설계서로 확인합니다.
- 세무 용어(E 묶음)는 지식베이스 정정사항 문구를 따릅니다. 모두 **(세무사 검토 필요)** 입니다.

## A. 계약 구조 (누가 내고, 누가 보장받고, 누가 받나)

| 용어 | 쉬운 설명 | 예시 |
| --- | --- | --- |
| 계약자 | 보험을 계약하고 보험료를 내는 사람(또는 법인). 해지·변경 권한도 계약자에게 있습니다. | 법인 경정기: 계약자 = ㈜OO 법인 |
| 피보험자 | 그 사람의 생명·건강이 보험의 대상이 되는 사람. 사망하면 보험금이 나옵니다. | 법인 경정기: 피보험자 = 대표이사 |
| 수익자 | 보험금을 받는 사람. 사망보험금 수익자, 만기·해지환급금 수익자로 나뉠 수 있습니다. | 법인 경정기: 수익자 = 법인. 유족으로 지정하면 세무 처리가 달라짐 (세무사 검토 필요) |
| 법인계약 구조 | 계약자·수익자 = 법인, 피보험자 = 대표(CEO·등기임원)인 구조. 메트 TheClassic 경정기는 계약자가 법인이어야 합니다. | "계약자는 법인(인감), 피보험자는 대표(서명)" |
| 타인의 사망보험 · 서면동의 | 계약자와 피보험자가 다르면 피보험자의 서면동의가 계약 체결 때까지 있어야 합니다. 없으면 계약 무효입니다. | 법인이 대표를 피보험자로 할 때 대표 자필 서명 필수 |
| 서면동의 철회 | 피보험자(대표)는 언제든 동의를 철회할 수 있고, 철회하면 계약이 해지됩니다. | 대표 교체·지분 분쟁 가능성이 있는 법인은 관리 리스크로 미리 안내 |
| 주계약 / 특약 | 주계약은 상품의 본체, 특약은 덧붙이는 옵션 계약입니다. 자동으로 붙는 특약(자동부가)도 있습니다. | TheClassic 경정기에는 종신전환특약·연금전환특약이 자동부가 |
| 보험가입금액 | 보장의 기준 금액. 사망보험금, 감액, 전환 계산의 기준이 됩니다. | 메트 달러 경정기 일반가입형 5만~500만달러 |
| 보험기간 / 납입기간 | 보장받는 기간 / 보험료를 내는 기간. 둘이 같으면 "전기납"이라고 합니다. | TheClassic: 90세 만기, 90세납(전기납), 월납 |
| 보장개시일 | 보장이 시작되는 날. 청약과 함께 첫 보험료를 내면 승낙 전 사고도 원칙적으로 보장합니다(고지의무 위반 등 예외). | 첫 보험료 출금일을 고객과 미리 확인 |
| 계약자 변경(명의변경) | 계약자를 바꾸는 것. 회사 승낙 사항이고 법인 → 대표 명의변경은 세무 쟁점이 큽니다. | 평가액 기준이 확정되지 않아 "확정 제안 금지" (세무사 검토 필요) |
| 지정대리청구 | 수익자가 직접 청구할 수 없을 때 미리 지정한 대리인이 보험금을 청구하는 제도. | 계약자·피보험자·수익자가 모두 같을 때 가능, 사망보험금은 제외 |
| 보험증권 | 계약이 성립했다는 증서. 받은 날이 청약철회 기간 계산의 기준이 됩니다. | 증권 전달 때 보장분석을 함께 해 주면 사후관리로 연결 |

## B. 보험료·환급 (돈이 어떻게 쌓이고 돌아오나)

| 용어 | 쉬운 설명 | 예시 |
| --- | --- | --- |
| 해약환급금(해지환급금) | 중도에 해지할 때 돌려받는 돈. 낸 보험료보다 적을 수 있습니다. | 달러 경정기 40세 남 일반, 1년차 해지 시 0달러 |
| 환급률 | 해약환급금 ÷ 그때까지 낸 보험료. 100% 미만이면 원금 손실입니다. | 메트 달러 경정기 40세 일반 10년 환급률 94.9% (비교자료 기준) |
| 순비용 | 낸 보험료 합계 − 해약환급금. 사실상 그 기간 보장받은 비용입니다. | 1억 보장 10년 순비용: 푸본현대 208만, 메트 달러 315만, 메트 원화 414만 (40세 일반, 비교자료) |
| 유해약환급금형 | 해약환급금을 정상적으로 주는 기준형. 저·무해약형 비교용으로만 쓰이고 실제 판매하지 않는 경우가 많습니다. | 백만인 종신 요약서: "유해약환급금형은 비교 안내용" |
| 저해약환급금형 | 일정 기간 해약환급금을 줄이는 대신 보험료가 싼 형태. 초기 해지하면 손해가 큽니다. | TheClassic: 3년 전 0%, 3~5년 50%, 5년~납입 끝 95%, 납입 후 100% (유해약형 대비 비율) |
| 무해약환급금형 | 납입기간 중 해약환급금이 아예 없는(0%) 형태. 보험료가 가장 쌉니다. | 모두의달러종신: 납입기간 중 0%, 납입 후 50% (유해약형 대비) |
| 체증형 | 시간이 지나면 사망보험금이 늘어나는 구조. 상품마다 속도와 상한이 다릅니다. | TheClassic 경정기: 10년 경과 후 매년 10%씩 / 백만인 달러종신: 매년 5%씩 150%까지 / 세븐PlusⅡ: 매년 20%, 30년 이후 700% |
| 단기납 | 납입기간이 5·7·10년처럼 짧은 종신보험. 납입 끝난 뒤 환급률이 오르는 구조가 많습니다. | 백만인 달러종신 5년납 40세 남 10년 환급률 124.9% (비교자료, 환율 리스크 별도) |
| 유지보너스 | 납입 완료 후 유지하면 적립액에 더해 주는 보너스. 해지하면 받지 못합니다. | 세븐PlusⅡ: 10년 7.5%, 20년 3.8% / 백만인 10년납: 39.7% |
| 적용이율 | 보험료 계산과 적립에 쓰는 이율. "수익률"이 아니므로 예금 금리처럼 말하면 안 됩니다. | TheClassic 달러: 10년 이내 3.75%, 이후 1.0% / 원화: 2.5%, 이후 1.0% |
| 계약자적립액 | 보험회사가 계약별로 쌓아 둔 적립금. 해약환급금·플러스기간 계산의 기초입니다. | 달러 경정기: 대출 원금·이자를 빼고 계산 |
| 감액 | 보험가입금액을 줄이는 것. 줄인 부분은 해지된 것으로 봅니다. | 일반 감액은 시점 제한 없음, 감액분 해약환급금이 적을 수 있음 |
| 감액완납 | 보험료 납입을 멈추고, 그때 해약환급금으로 가입금액을 줄여 계약을 유지하는 것. | TheClassic: 계약 5년 경과 후, 회사 승낙 필요 |
| 보험계약대출(약관대출) | 해약환급금 범위 안에서 보험회사에서 돈을 빌리는 것. 이자가 붙고 보험금에서 차감됩니다. | TheClassic: 원화 대출, 전기납 + 10년 미경과 + 피보험자 75세 이하일 때만 |
| 추가납입 | 기본보험료 외에 돈을 더 넣는 것. 상품마다 가능 여부·한도가 다릅니다. | TheClassic은 일반 추가납입 규정 없음(원화고정납입용 추가보험료만). 연금전환 후에는 기본보험료 100% 한도 |
| 중도인출 | 해지하지 않고 적립액 일부를 꺼내 쓰는 것. | TheClassic: 고정납초과보험료 자동인출 외 중도인출 불가 |
| 원화고정납입(달러형) | 달러 상품을 매달 같은 원화 금액으로 내는 옵션. 남는 원화는 추가보험료로 적립됩니다. | 추가보험료 한도: 1회 기본보험료의 50%, 총액도 50% 이내 |
| 원화환산납입·지급 | 달러 상품의 보험료·보험금을 원화로 내고 받는 특약. 환율에 따라 원화 금액이 달라집니다. | 법인이 원화 통장으로 납입 가능, 환율 리스크는 남음 |
| 플러스보험기간 | 달러 경정기에만 있는, 90세 만기 뒤 5년 연장 보장. 만기 적립액이 0보다 클 때만 적용됩니다. | 대출 잔액이 있으면 그만큼 줄어듦 |
| 종신전환 | 경정기를 종신보험으로 바꾸는 것. 기존 계약을 전부 해지하고 해약환급금을 종신 보험료로 일시납합니다. | TheClassic: 7년 이상 정상 유지 후 가능, 전환 시점 나이·요율 적용 |
| 연금전환 | 계약을 연금으로 바꾸는 것. | TheClassic: 계약일부터 7년 경과 + 해약환급금 1,000만원(달러 1만달러) 이상 |
| 조기 계약전환 | 정해진 사유가 생기면 7년 전에도 종신으로 전환할 수 있는 옵션. | 36회 이상 납입 + 폐업 / 3개월 이상 입원 / 대표이사 변경 / 최대주주 변경 |
| 납입최고 · 실효 | 보험료가 밀리면 회사가 14일 이상 기간을 주고 독촉(납입최고)하고, 그래도 안 내면 해지(실효)됩니다. | 최고 기간 끝난 다음 날 해지 |
| 부활 | 연체로 해지된 계약을 되살리는 것. 연체 보험료와 이자를 내고 다시 심사받습니다. | TheClassic: 해지일부터 3년 이내 청약 |
| 선납 | 보험료를 몇 달치 미리 내는 것. 상품마다 한도가 다릅니다. | 메트 경정기 12개월, 일부 회사 6개월 |
| 납입유예 | 출산·육아휴직 때 보험료 납입을 잠시 미루는 특약. | 계약당 1회, 6개월 또는 12개월 |
| 보험가격지수 | 같은 보장을 업계 평균 대비 얼마에 파는지 보여 주는 지수. 높을수록 상대적으로 비쌉니다. | 달러 경정기 40세 남: 일반 100.2%, 간편 121.2% |

## C. 심사 (가입이 되느냐, 얼마까지 되느냐)

| 용어 | 쉬운 설명 | 예시 |
| --- | --- | --- |
| 계약 전 알릴 의무(고지의무) | 청약할 때 질문받은 건강·직업 등 중요 사항을 사실대로 알리는 의무. **청약서에 서면으로** 해야 하고, 설계사에게 말로 한 것은 효력이 없습니다. | "5년 이내 암 진단, 2년 이내 수술·입원" 질문을 대표와 함께 하나씩 확인 |
| 고지의무 위반 | 고의·중과실로 사실과 다르게 알리면 계약 해지나 보장 제한이 될 수 있습니다. 일정 기간(보장개시 후 2년, 계약 후 3년 등)이 지나면 해지할 수 없습니다. | 설계사가 고지를 방해하거나 "안 써도 된다"고 하면 회사가 해지할 수 없지만, 설계사 책임 문제가 됩니다 |
| 일반심사(일반가입) | 건강 질문이 자세하고 심사가 엄격한 대신 보험료가 싼 방식. | 메트 원화 경정기 40세 1억: 일반 월 36.7만원 |
| 간편심사(간편가입) | 질문을 줄여 유병자·고령자도 가입하기 쉬운 방식. 보험료가 비쌉니다. | 같은 조건 간편 월 44만원(약 20% 높음), 10년 환급률은 1%p 내외 낮음 |
| 간편가입 2년 50% | 간편가입은 계약 후 2년 안에 질병 등(재해 외)으로 사망하면 보험금의 50%만 나옵니다. | 고령 고객 제안 때 반드시 먼저 고지 |
| 간편가입 3개월 규칙 | 일반심사가 가능한 사람이 간편으로 들면 보험료 비교 설명 + 계약자 확인서가 필요합니다. 3개월 안에 일반심사 보험으로 갈아타면 간편 계약은 무효 처리될 수 있습니다. | 청약 직전 3개월 내 일반심사 가입 이력이 있으면 일반가입형으로 재심사 안내 |
| 건강진단(진단계약) | 가입금액·나이에 따라 회사가 건강검진을 요구하는 계약. 진단을 지원받은 계약은 청약철회가 안 됩니다. | 고액 경정기는 진단 일정까지 계산해 청약일 잡기 |
| 선심사 | 제안(PC) 전에 가입 가능 여부를 먼저 보험사에 물어보는 것. | "보통 P를 제안하기 전에 선심사를 맡기는 게 원래 순서" |
| 언더라이팅(인수심사) | 보험사가 계약을 받을지, 어떤 조건으로 받을지 정하는 심사 전체. | 건강 심사 + 재정심사 + 직업 심사 |
| 재정심사 | 계약자가 보험료를 낼 능력이 있는지, 보장 규모가 소득·재산에 맞는지 보는 심사. | 고액 계약은 소득서류·재무제표 제출을 요구받을 수 있음 |
| 재정질의서 | 재정심사 때 소득·재산을 적어 내는 질문지. | 신한 세븐종신 예시: 기계약 합산 5억 초과~7억 이하는 재정질의서로 심사 |
| 고지소득 | 청약서·질의서에 고객이 스스로 적는 소득. 직업·보험료와 앞뒤가 맞아야 합니다. | NOT TO DO: 월납 100만원 가입인데 월소득 100만원 고지 |
| 피보험이익 | 그 사람이 사망했을 때 생기는 경제적 손실의 크기. 보험사는 이를 근거로 사망보험금 한도를 정합니다. | 신한 예시(클래식↑ 등급): 40~49세 연간소득 × 30배까지 인정 |

| AP (초회면담) | 첫 미팅. 산출물은 계약이 아니라 **다음 약속과 소개**. | 상품명을 꺼내면 채점 −5점 |
| PC (제안) | 지난번 문제에 대한 해결책을 숫자로 보여 주는 미팅. | A안 / B안 중 고르게 하기 |
| C (계약·클로징) | 청약을 받는 단계. | "이번 달에 서류가 들어가야 합니다. 서류는 언제까지 준비 가능하실까요?" |
| F.F (Fact Finding) | 질문으로 고객의 사실 정보를 모으는 것. | 고객 입에서 나온 숫자만 근거로 씀 |
| 선거절처리 | 고객이 거절할 이유를 먼저 꺼내 풀어 두는 것. | "단점을 먼저 말해 두면 나중에 방어가 됩니다" |
| 조인웍 | 다른 지점원·전문직과 함께 진행하는 협업 계약. 역할·분배를 착수 전에 합의. | 기본 5:5 예시, 원수사 합산 인수 사전 확인 |
