# 단기납 달러종신 (목적자금 + 사망보장 + 비과세, "백만종")

## 한 줄 정의
7년(또는 5·10년) 단기납 후 10년 시점 해약환급률이 원금을 넘어서는 달러 종신보험으로, 납입 중에는 사망보장, 완납 후에는 목적자금(유학·은퇴·자녀 이전)으로 쓰고 10년 이상 유지 시 이자차익 비과세를 받는 컨셉. 대표 상품: 메트라이프 "백만인을 위한 달러 종신보험".

## 대상 업체 신호
- 목적자금 마련 니즈 크고 상속 니즈 작은 고소득자(의사, 연예인 등), 나이가 어려 상속 니즈 작음
- 병원 원장: "생각보다 사망 보장 니즈가 없으세요." 오히려 사모님을 만나는 게 사망보험 니즈가 빠르다.
- 40대~50대 초반 중년 남성: 자녀 성장 중, 목돈 필요 시점
- 해외 관련 지출이 많은 업종, 유학·해외여행 자금
- 배당·이자소득이 많아 금융소득종합과세 대상인 사람
- 경정기 환급률 100% 미만이 불만인 사람
- 기존 계약자 2년 경과 고객(추가 가입 제안이 잘 됨), 업력 짧은 전문직의 주변 고소득 지인(월 30~50만원 소액)

## 고객 니즈/페인포인트
- 원화 가치 하락 우려, 달러 자산 필요 ("원화가 녹는다")
- 은행 예적금으로 달러를 이자 붙여 모을 수단이 마땅치 않음
- 금융소득 연 2,000만원 초과 시 종합과세 → 이자의 실질 수익이 절반 (금리 4%, 10년 적금 가정 시 원금 대비 이자율 20.8% → 10.4%), 건보료 인상

## 해결 구조
1. 납입 구조: 5년(5+5), 7년(7+3), 10년납 중 보통 7+3. 10년 이상 유지 시 이자차익 비과세. 10년납 17~18%, 7+3은 21~22% 수준
2. 녹취상 상품 수치: 7년 납입 완료 시 100%, 10년 시점 해약환급률 124.8% 이상
3. 사망보험금 체증형 구조
4. **특이 기능:** 7년 경과 후 보장성 → 저축성 전환 가능(1회, 일부만 전환 가능). 저축성 전환 후 미국 공시이율 적용, 추가납입 가능, 피보험자 교체 가능.
5. 저축성 전환 시 세무 이슈 (강의 내 설명): 전환 시점부터 다시 10년을 채워야 비과세 / 저축성은 비과세 한도 규정 적용 → 보장성과 저축성을 나눠(반반, 80:20 등) 전환. [저축성 보험 비과세 한도·요건은 소득세법 시행령 확인필요, 일반지식]
6. 원화고정납입: 계약금액 약 10%를 원화고정으로 권유(30%까지 가능), 예: 300 제안 → 330 계약.
7. 활용: "달러 모으는 수단 + 납입 중 상속리스크 헷지 + 금융소득종합과세 대상에서 제외 (건보료 인상, 세무이슈x)" / 피보험자를 자녀로 바꿔 "비과세 통장"으로 넘겨주는 아이디어(강의 중 비과세 요건과의 관계는 "계약자 기준"이라는 대화가 있었으나 확정되지 않음).

## 연계 보험상품 및 연결 논리
- 제로백(원화 원금형 종신)과 비교: 차이는 달러 여부, 사망보험금 크기, 환급률. "사망 보험금 니즈가 크지 않으시다면 제로백보다는 백만종이 목적자금 마련 측면에서 훨씬 유리". 단 수수료·사망보장 관리 때문에 제로백을 먼저 추천하는 경우가 많다.
- 상속세 재원 목적만이라면 이 상품만으로는 한계, 다른 종신 설계가 낫다.

## AP에서 던질 질문
- "자녀분 유학이나 해외 계획 있으세요?"
- "달러 자산은 어떻게 갖고 계세요? 예금이나 ETF로 모으고 계세요?"
- "금융소득이 연 2천만원 넘으시죠? 건보료도 같이 오르셨을 거고요." [구성 예시]
- "10년 뒤에 목돈이 필요한 일이 있으세요?"

## PC/제안 단계 화법
- 비교 흐름: 자산 포트폴리오와 달러 필요성 → 달러 모으는 방법(예적금, ETF) → 금리 4% 10년 적금 20.8% → 금융소득종합과세로 실질 10.4% → 이 상품 7+3 약 21~22% 비과세.
- 특징이 아니라 이익으로: "비과세다" X → 아낄 수 있는 금액으로
- 강사 개인 경험: 2020년 비슷한 5년납 상품 가입, 환율 1,030원 → 해지 시 1,400원. "가입하고 이거 내가 낼 수 있나 싶었는데 금세 5년 되고 7년 되고 나중에 보면 든든해요."

## 자주 나오는 반론과 대응
- "법인으로 가입하면 비용처리 되나?": 법인 가입은 가능하나 전액 비용처리는 안 된다는 것이 다수설. 비용처리를 원하면 법인은 경영인정기보험. 이 상품은 주로 개인 가입.
- "환율이 이미 많이 올랐는데": 원화고정납 비율을 10% 정도로 권유(높은 환율 고려).

## 주의사항·리스크
- 2~3년 전 고환급률 단기납 상품들은 금감원 제재로 환급률이 낮아졌다. 현행 조건 확인 필수.
- 보험사 "내부 교육용, 고객 상담 시 직접 사용 불가" 자료를 캡처해 고객 자료로 쓰면 이슈. 청약서 앞 설명 자료 중심으로.
- 10년 전 해지 시 이익에 과세, 저축성 전환 시 10년 재기산·한도 적용.
- 환율 변동 리스크, 확정 수익 표현 금지.

## 필요 자료 / 협업 자격사
- 소득 구조(금융소득 규모), 목적자금 시점·금액, 기존 달러 자산, 가족계획.
- 세무사(비과세 요건·금융소득종합과세), 보험 설계.
