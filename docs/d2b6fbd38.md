# 04. 영업 흐름 한 장 요약

- 기준일: 2026-10-04
- 근거:, AP15단계_표준.md,
- 핵심 문장: **"보험을 먼저 말하지 않는 사람, 그러나 마지막 한 칸을 비워두지 않는 사람."** (세일즈프로세스 7장)

---

```
 (명단 20~30명) (만날 명분) (다음 약속+소개) (숫자+A/B안) (서류 일정) (유지율 = 소득)
```

| 단계 | 단 하나의 목표 | 꼭 할 것 | 하지 말 것 | 도구 |
|---|---|---|---|---|
| **PS** 가망고객발굴 | 만날 사람 확보 | 가망고객 20~30명 상시 유지. 관계·자금 여력·니즈·의사결정권·진행상황 기록. 진입 타이밍은 결산·가결산 미팅 | 명단만 적고 방치 | PS리스트(관계온도 A/B/C) |
| **TA** 전화약속 | 미팅 확약(언제, 어디서) | 만날 명분을 판다. 이지선다 "화요일 오후와 목요일 오전 중 어느 쪽이 덜 번잡하시겠습니까?" 3분 이내 | 전화로 내용 설명 ("경영인정기보험이라는 게 있는데요" X) | |
| **AP** 초회면담 | **다음 약속 + 소개** | AP 15단계(20분). 질문으로 니즈 끌어내기. 고객 입에서 나온 숫자만 근거. "오늘 말씀을 바탕으로 다음번에 해오겠습니다" | 상품명·환급률·수수료 언급 (채점 −5점) | **AP 스크립트 생성기** |
| **(선심사)** | 가입 가능 여부 확인 | PC 전에 선심사·재정심사 범위 확인 | 가입 안 되는 금액으로 제안 | **경정기 시뮬레이터** (재정 참고) |
| **PC** 제안 | 지난번 문제의 해결책 제시 | AP 복기로 시작 → 전/후 비교 → 숫자 시뮬레이션 → A안/B안 → 마지막 장 D-day 일정 | "하실래요?" (할까 말까 고민하게 만듦) | **경정기 시뮬레이터**, 실제 가입설계서 |
| **C** 계약 | 청약 | 할 것을 전제로 대화: "이번 달에 서류가 들어가야 합니다. 서류는 언제까지 준비 가능하실까요?" 질문 후 기다리기. 청약 당일 동행 | 침묵을 못 견뎌 먼저 금액 깎기 | 03_청약서_작성가이드 |
| **소개·사후관리** | 관계 유지·추가 계약 | 계약 순간·AP 직후·성과 시점에 소개 요청(조건·인원 특정). 증권 전달 때 보장분석, 3개월 차 관리, 결산 1개월 전 브리핑 | 계약 후 연락 끊기 | PS리스트 기록 |

### 숫자로 보는 깔때기
- "AP 후 계약까지 가는 비율이 15% 정도, 7개를 보면 1개 성사" → **계약 1건을 원하면 AP 약 7건**을 잡아야 합니다.

### 전문직 지점원의 방식: 주도형
- 대가형("이익소각 해드렸으니 보험 들어주세요")은 고액 계약이 어렵고 고객이 "억지로 가입한 보험"으로 기억합니다.
- 주도형은 용역을 충분히 제공하고, 고객 상황에서 보험이 독립적으로 가치 있을 때 별도로 제안합니다. 보험은 컨설팅 대가가 아니라 **구조상 필요한 재원**으로 설명합니다.
