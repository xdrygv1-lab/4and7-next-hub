# 약관정리_TheClassic달러경영인정기 (메트라이프)

> 이 문서는 주계약(보통약관) 기준으로, 기존에 없던 운용 조건을 보완한 것입니다. 조항 번호는 주계약 약관 기준입니다.
> 중요: 이번 약관 파일에는 특약 본문이 들어 있지 않습니다. 특약 색인에 (무)종신전환특약, (무)신연금전환특약_(가입시점), (무)달러연금전환특약_(가입시점), 원화환산납입서비스특약, 원화환산지급서비스특약 등이 모두 "별도약관"으로만 표시되어 있어, 해당 특약의 세부 조건은 "약관에 없음(별도 특약약관 확인 필요)"으로 표기했습니다.

## 0. 요약서 대비 새로 확인된 핵심

| 항목 | 약관 확인 내용 | 조항 |
|---|---|---|
| 감액완납 | 계약일로부터 5년 경과 이후 가능, 회사 승낙 필요 | 제21조 ①2호, ⑤ |
| 조기 계약전환 옵션 | 기본보험료 36회 이상 납입 + 폐업 / 3개월 이상 입원·요양 / 대표이사 직위 변경 / 최대주주 지위 변경 시 회사가 정한 전환상품으로 전환 | 제45조 |
| 보험계약대출 | 원화 대출. 전기납 + 계약일부터 10년 미경과 + 피보험자 75세 이하일 때만 신청 가능 | 제34조 ①, ⑤ |
| 중도인출 | 고정납초과보험료 자동인출 외 계약자적립액 중도인출 불가 | 제33조의2 ② |
| 자동대출납입 | 적용하지 않음 | 제26조 |
| 계약자 변경 | 회사 승낙 사항. 법인에서 대표로의 명의변경 전용 조항은 없음 | 제21조 ①3호, ⑥ |
| 피보험자 서면동의 철회 | 피보험자는 언제든지 장래를 향해 철회 가능, 이 경우 계약 해지 | 제30조 ② |

## 1. 감액완납

| 구분 | 내용 | 조항 |
|---|---|---|
| 정의 | 보험료 납입을 중단하는 대신 보험가입금액을 감액하는 것 | 제21조 ⑤ |
| 가능 시점 | 계약일로부터 5년이 경과한 이후 | 제21조 ⑤ 단서 |
| 절차 | 계약자 신청 + 회사 승낙 (승낙은 서면 또는 보험증권 뒷면 기재로 통지) | 제21조 ① |
| 감액 후 가입금액 | 변경 당시 제33조에 따른 해약환급금을 기준으로 새로 정함 | 제21조 ⑤ |
| 감액완납 후 체증(매년 10%) 유지 여부 | 약관에 없음 | |
| 감액완납 후 플러스보험기간 적용 여부 | 약관에 없음 (플러스보험기간은 만기 시 계약자적립액 > 0 조건만 규정) | 제3조의3 ③ |

참고: 일반 감액(보험료 계속 납입)

| 구분 | 내용 | 조항 |
|---|---|---|
| 처리 | 감액된 부분은 해지된 것으로 보고, 해약환급금이 있으면 지급. 해약환급금이 없거나 가입 시 안내보다 적을 수 있음 | 제21조 ③ |
| 승낙 통보 | 증액 또는 감액 신청 시부터 2주일 이내 | 제21조 ④ |
| 적용 시점 | 회사 승낙일 이후 최초로 도래하는 월계약해당일부터 변경 가입금액·기본보험료 적용 | 제21조 ④ |
| "이미 납입한 보험료" 조정 | 감액직전 이미 납입한 보험료 × (감액 후 가입금액 ÷ 감액 전 가입금액) | 제21조 ⑧, 제3조의2 ①4호(3) |
| 시점 제한 | 일반 감액에는 시점 제한 규정 없음 (5년 제한은 감액완납에만 있음) | 제21조 |

- 저해약환급금형이므로 5년 경과 직후 감액완납 시 기준 해약환급금은 유해약환급금형 대비 95% 구간(경과월수 60개월이 지난 후 도래하는 월계약해당일부터) 금액이 됩니다 (제33조 ① 유의사항 다).

## 4. 조기 계약전환 옵션, 기타 전환 제도

|---|---|---|
| 신청 요건(기간) | 기본보험료를 납입한 기간이 3년 이상 경과한 계약(기본보험료 36회 이상 납입) | 제45조 ① |
| 승인 | 계약자 신청 + 회사 승낙 | 제45조 ① |
| 전환 대상 | "회사가 정한 전환상품" (상품명은 약관에 없음) | 제45조 ① |
| 사유(계약자 또는 피보험자) 및 구비서류 | 1. 영위하는 사업장의 폐업: 폐업사실증명원<br>2. 3개월 이상의 입원치료 또는 요양을 요하는 상해·질병 발생: 입·퇴원확인서<br>3. 계약체결 당시 대표이사였던 직위가 전환신청 당시 변경된 경우: 법인등기부등본<br>4. 계약체결 당시 최대주주였던 직위가 전환신청 당시 변경된 경우: 주주명부, 주식 등 변동상황명세서 | 제45조 ② |
| 처리 방식 | 잔여보험료를 납입하지 않고 이 계약을 해지한 후 전환상품으로 전환 | 제45조 ③ |
| 전환 후 적용 약관 | 전환된 상품의 약관 및 기초서류 | 제45조 ④ |
| 불이익 | 해약환급금이 가입 시 안내한 금액보다 적어질 수 있음. 회사가 정한 최저가입금액 기준 미달 시 추가 납입금 발생 가능 | 제45조 ⑤ |
| 기타 전환 제도 | 약관에 없음 | |

## 5. 플러스보험기간

요약서에 정리된 내용(기간 5년, 계약자적립액 > 0 조건, 일시납 환산) 외에 약관에서 추가 확인된 사항만 적습니다.

| 구분 | 내용 | 조항 |
|---|---|---|
| 기본보험기간 끝 | 피보험자의 90세 연계약해당일의 전일까지 | 제3조의3 ② |
| 보장개시일 | 기본보험기간이 만료되는 날의 다음날 | 제3조의3 ③ |
| 적용 방식 | 조건 충족 시 자동 적용 (별도 신청 규정 없음) | 제3조의3 ③ |
| 일시납 재원 | 기본보험료 계약자적립액 + 원화고정납입용 추가보험료 적립액 합산에서 보험계약대출 원금·이자 차감액. 별도 보험료 추가 납입 규정 없음 | 제3조의3 ③, ④ |
| 보장 | 플러스보험기간 중 사망 시 플러스보험기간의 보험가입금액 | 별표1 2. |
| 미적용 시 | 계약자적립액이 0을 초과하지 않으면 기본보험기간 만료 시점부터 계약 효력 없음 | 제23조 ② |
| 체증, "이미 납입한 보험료와 해약환급금 중 큰 금액" 비교 | 기본보험기간 지급기준에만 있음 (플러스보험기간 지급기준표에는 없음) | 별표1 |

- 요약서 예시상 50년(만기) 해약환급금이 0달러이므로, 실제 계약에서 플러스보험기간이 적용될지는 설계서로 확인해야 합니다.

| 중도인출 횟수 제한 | 약관에 없음 | |

| 원화 환산 시 적용 환율, 환산기준일 | 약관에 없음 (원화환산납입서비스특약 별도약관) | |

## 8. 계약자·수익자 변경

| 구분 | 내용 | 조항 |
|---|---|---|
| 계약자 변경 | 회사의 승낙을 얻어 변경 가능 (보험가입금액, 감액완납, 계약자, 기타 계약내용이 승낙 사항) | 제21조 ①3호 |
| 계약자 변경 후 | 회사는 변경된 계약자에게 보험증권·약관 교부, 요청 시 중요 내용 설명 | 제21조 ⑥ |
| 수익자 변경 | 회사 승낙 불필요. 단, 변경된 수익자가 회사에 대항하려면 계약자가 회사에 통지해야 함 (미통지 상태에서 변경 전 수익자에게 지급되면 변경 수익자에게 지급 안 함) | 제21조 ② |
| 계약자와 피보험자가 다를 때 수익자 변경 | 보험금 지급사유 발생 전에 피보험자의 서면(전자서명 전자문서 포함) 동의 필요 | 제21조 ⑦ |

## 13. 실무 체크포인트

1. 감액완납은 계약일로부터 5년 경과 후에만 가능하고 회사 승낙 사항입니다 (제21조 ⑤). 5년 이내에 납입이 어려우면 일반 감액(감액분 해지 간주, 제21조 ③)이나 해지만 남고, 3년 이전은 저해약 0% 구간입니다.
2. 대표 퇴임, 지분 변동, 폐업 시 제45조 조기 계약전환 옵션(36회 이상 납입, 서류: 법인등기부등본, 주주명부·주식 등 변동상황명세서, 폐업사실증명원 등)을 먼저 검토합니다. 전환상품은 "회사가 정한 전환상품"이므로 상품명과 조건은 회사에 확인해야 합니다.
3. 법인에서 대표 개인으로의 계약자 변경은 일반 계약자 변경(제21조 ①3호, 회사 승낙)으로만 규정되어 있습니다. 변경 시점 평가액, 퇴직금 대체 지급 등 과세 문제는 세법 확인필요.
4. 피보험자(대표)는 서면동의를 언제든지 철회할 수 있고 철회 시 계약이 해지됩니다 (제30조 ②). 대표 교체나 분쟁 가능성이 있는 법인은 계약 관리 리스크로 안내합니다.
5. 보험계약대출은 원화로, 계약일부터 10년 이내이면서 피보험자 75세 이하일 때만 가능합니다 (제34조 ⑤). 10년 경과 후에는 대출을 유동성 용도로 쓸 수 없고, 대출 잔액은 플러스보험기간 재원에서도 차감됩니다.
6. 중도인출은 원화고정납입의 자동인출 외에는 불가하고 (제33조의2 ②), 원화고정납입용 추가보험료는 1회 기본보험료의 50%, 총액 기본보험료 납입총액의 50% 한도입니다 (제3조의2 ①3호).
7. 종신전환, 연금전환, 원화 환산 환율 기준은 주계약 약관에 없으므로 상담 전에 각 특약 약관을 별도로 확보합니다. 법인 계약자가 전문금융소비자(주권상장법인 등)에 해당하면 청약철회가 불가합니다 (제18조 ①1호).
