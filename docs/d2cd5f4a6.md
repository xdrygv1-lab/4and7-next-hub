# 약관 정리: TheClassic 달러경영인정기보험

> **한눈에** 메트라이프 TheClassic 달러경영인정기보험 주계약 약관에서 운용 조건(감액완납, 조기 전환, 대출, 명의변경, 해지)을 뽑았습니다. 법인 대표에게 가입 후 관리 방법을 설명할 때 씁니다. 특약 본문은 약관에 없어 종신·연금 전환 세부 조건은 별도 특약약관으로 확인해야 합니다.
> 내부 참고용. 고객에게는 가입설계서·상품설명서 기준으로 안내.

## 핵심 조건 표
| 항목 | 약관 내용 | 조항 |
|---|---|---|
| 기준통화 | 납입·지급·인출 모두 **달러** | 제1조 |
| 감액완납 | 계약일부터 **5년** 경과 후, 회사 승낙 | 제21조 ⑤ |
| 조기 계약전환 | 기본보험료 **36회** 이상 + 4가지 사유 시 회사가 정한 전환상품으로 | 제45조 |
| 보험계약대출 | **원화** 대출. 전기납 + 계약일부터 **10년** 미경과 + 피보험자 **75세** 이하 | 제34조 ①, ⑤ |
| 중도인출 | 고정납초과보험료 자동인출 외 **불가** | 제33조의2 ② |
| 원화고정납입 추가보험료 | 1회 기본보험료 **50%**, 총액 기본보험료 납입총액 **50%** 한도 | 제3조의2 |
| 자동대출납입 | 적용하지 않음 | 제26조 |
| 플러스보험기간 | 90세 만기 시 계약자적립액(대출 차감) 0 초과면 자동 적용 | 제3조의3 |
| 종신·연금 전환 | 주계약 약관에 없음 (별도 특약약관 확인 필요) | |

조기 계약전환 사유: ① 사업장 폐업 ② 3개월 이상 입원·요양 ③ 계약 당시 대표이사 직위 변경 ④ 계약 당시 최대주주 지위 변경. 계약을 해지하고 전환상품으로 넘어갑니다.

## 이런 고객에게
- 달러 자산으로 대표 유고 대비 보장을 마련하려는 법인
- 퇴임·지분 변동·폐업 가능성이 있어 중간에 구조를 바꿀 여지가 필요한 대표
- 납입 여력이 바뀔 수 있어 5년 후 감액완납 선택지를 원하는 법인

## 설명할 때 꼭 말할 것
- ⚠ 감액완납은 **5년 경과 후**만 가능. 그 전에는 일반 감액(감액분 해지 간주)이나 해지만 남고, 3년 이전은 저해약 **0%** 구간
- ⚠ 대표(피보험자)는 서면동의를 **언제든 철회** 가능하고, 철회하면 계약이 해지됩니다
- ⚠ 원화 환산 시 보험료·보험금·해약환급금 손실이 생길 수 있고 손실은 계약자 몫
- ⚠ 조기 계약전환 시 해약환급금이 가입 시 안내보다 적을 수 있음
- 대출은 10년 이내만 가능하고, 대출 잔액은 플러스보험기간 재원에서도 차감

> "대표님, 이 상품은 5년이 지나면 납입을 멈추고 보장을 줄여 유지하는 길이 있고, 퇴임이나 지분 변동이 생기면 36회 납입 후 다른 상품으로 넘길 수 있는 조항이 있습니다."

## 자주 헷갈리는 점
| 헷갈리는 점 | 정리 |
|---|---|
| 일반 감액도 5년 제한? | 5년 제한은 **감액완납에만**. 일반 감액은 시점 제한 없음 |
| 대표 퇴임 시 명의를 대표로? | 법인→개인 전용 조항 없음. 일반 계약자 변경(회사 승낙). 세무 처리는 세무사 검토 사항 |
| 수익자 변경도 승낙 필요? | 회사 승낙 불필요. 단 회사에 통지해야 대항 가능, 피보험자 서면동의 필요 |
| 간편형도 조건이 같다? | 대부분 같지만 간편형은 **2년 내 재해 외 사망 시 50%** 지급, 3개월 내 일반심사 가입 시 무효 가능 |
| 청약철회는 항상 가능? | 전문금융소비자(주권상장법인 등) 법인 계약자는 불가 |

## 해지 시 알아둘 것
- 해약환급금은 청구 접수일부터 **3영업일** 이내 지급, 청구권 소멸시효 **3년**
- 위법계약 해지(체결일부터 **5년** 이내, 안 날부터 **1년** 이내)는 계약자적립액 반환
- 연체 시 납입최고 **14일** 이상, 해지 후 **3년** 이내 부활 청약 가능

## 꼭 확인할 것
- [ ] 종신전환·연금전환·달러연금전환 특약 약관을 별도로 확보
- [ ] 원화 환산 환율·환산기준일 (원화환산납입·지급서비스특약 확인 필요)
- [ ] 조기 계약전환 시 "회사가 정한 전환상품"의 상품명·조건
- [ ] 감액완납 후 체증 유지, 플러스보험기간 적용 여부 (약관에 없음, 확인 필요)
- [ ] 플러스보험기간 실제 적용 여부는 설계서로 확인
- [ ] 계약자 변경·전환 시 세무 처리는 세무사 검토 사항
