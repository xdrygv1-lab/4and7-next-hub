# 사근복 자기주식·지분 출연형 활용 (보조 컨셉)

## 한 줄 정의

- 법인이 보유한 자기주식이나 대주주·차명주주 주식을 기금에 출연해 손비 처리, 차명주식 회수, 잉여금 인출, 승계 대비를 설계하는 활용법 [기업의별 특수형태, 컨셉교육 11]

## 대상 업체 신호

- 과거 자본거래로 취득한 자사주 보유 법인, 2026 자기주식 소각 의무화 대응 필요 법인, 차명주식, 시가 대비 자본금이 작은 비상장법인 [기업의별]

## 고객 니즈

자료에서 이 컨셉에 대한 해당 내용을 찾지 못함.

## 해결 구조

**해결 구조**

- 차명주식 회수: 차명주주가 기금에 기부(「소득세 신고시 비용인정」), 「법 인 : 자기주식으로 출연할 경우 법인은 손비 처리」. 단 기금이 주주가 되어 「근로자측 위원이 회사운영에 개입 여지」, 미배당 시 무수익자산 문제 제기 가능 [기업의별 특수형태 3-1]
- 잉여금 인출: 대표 주식 양도 → 법인 자기주식 출연 손비 → 기금 이익소각(감자) 대금 귀속. 배우자 증여공제(6억) 활용 변형안 [같은 자료 3-2]
- 가업승계: 자기주식 40% 출연으로 상속가액 140억 → 70억 예시, 업무무관자산 출연으로 가업승계 요건 [같은 자료 3-3]
- 「출연시점에 수년치의 복리후생 집행 누적예상액을 일괄 기부함으로써 주식가치를 낮출 수 있음」 [같은 자료 2-1]
- 유상증자 참여: 출연받은 자사주 보유 시 기본재산 20% 범위
