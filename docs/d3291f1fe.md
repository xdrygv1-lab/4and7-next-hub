# 메트라이프 모두의달러종신 요약

> 상담 전 확인용 지식파일. 수치는 상품요약서 원문 기준이며, 세부 조건은 약관 확인 필요.
> 원문 기준일: 파일명 표기 20260701 (v2)

## 1. 한 줄 요약

사망보험금을 달러로 지급하는 순수보장형 종신보험(무해약환급금형)으로, 7년납부터 30년납, 55세~80세납까지 납입기간 선택 폭이 넓고 암, 뇌심, 수술, 입원 등 선택특약 30여 종과 사망보험금유동화특약을 붙일 수 있는 범용형 상품입니다.

## 5. 주요 기능

| 기능 | 내용 |
|---|---|
| 보험료 납입면제 | 납입기간 중 동일한 재해(주보험 지급사유 주석에는 "재해 또는 재해이외의 동일한 원인")로 여러 신체부위 장해지급률 합산 50% 이상 시 차회 이후 면제. 특이사항과 주석의 표현이 달라 약관 확인 필요 |

| 사망보험금유동화 | 사망보험금유동화특약(자동부가): 유동화 기간 동안 매년 주계약 가입금액을 감액하고 감액분 해약환급금을 유동화 금액으로 지급 |

## 7. 영업에 중요한 유의사항

* 납입기간 전체 동안 해약환급금이 0%입니다. 20년납이면 20년간 해지 시 환급금이 없습니다.
* 납입 완료 후에도 해약환급금은 유해약환급금형의 50% 수준이며, 예시상 원금 회복은 25년과 30년 사이입니다.
* 달러 기본통화로 환율에 따라 원화 환산 보험료, 보험금이 변동됩니다.
* 사망보험금유동화특약은 가입금액을 매년 감액하는 방식이므로, 유동화 시 사망보험금(상속재원)이 줄어듭니다.
* 갱신형 특약은 갱신 시 보험료가 변동될 수 있고, 납입면제 상태여도 갱신 후에는 보험료를 내야 합니다.
* 계약전 알릴의무 위반 시 보장개시일부터 2년(건강진단 계약은 1년) 이내 해지 가능.
* 타인의 사망보장 계약은 체결시까지 피보험자 서면동의가 없으면 무효입니다.
* 해약환급금 예시표 납입누계 행 정렬 오류 가능성 (4장 참고). 원본 PDF로 확인 후 고객 제시.

## 8. 영업 포인트

* 납입기간 11종(7/10/15/20/25/30년납, 55/60/65/70/80세납)으로 대표의 은퇴 시점이나 현금흐름에 맞춰 납입 종료를 설계할 수 있습니다.
* 가입금액 최대 500만달러로 고액 상속재원 설계가 가능하고, 최소 1만달러, 월 30달러부터 가입 가능해 자녀, 손주 계약까지 폭넓게 활용됩니다.
* 사망보장에 더해 암, 뇌심, 치매, 13대 납입면제와 페이백을 한 계약에 묶을 수 있어 "상속재원 + 본인 건강보장"을 함께 제안할 때 유리합니다.
* 사망보험금유동화특약이 자동부가되어 있어, 노후 생활비가 필요할 때 사망보험금 일부를 유동화하는 선택지를 설명할 수 있습니다 (그만큼 상속재원 감소).
* 상속세 재원, 계약자/수익자 설계, 유동화 금액의 과세 여부는 세법 확인필요.
