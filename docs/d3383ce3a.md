## 1. 청약 전 체크리스트 (출력용 1쪽)

### 1-1. 상품·심사
- [ ] **선심사를 먼저 넣었다.** "보통 P를 제안하기 전에 선심사를 맡기는 게 원래 순서" (설명 다 했는데 가입이 안 되는 상황 방지) (미팅프로세스 3-1)
- [ ] **일반심사 / 간편심사 선택 이유**를 고객에게 설명했다. 간편은 보험료가 약 20% 높고, 같은 예산이면 보장금액이 약 17% 줄어든다. (06 시뮬레이션)
- [ ] 일반심사가 가능한 사람을 간편으로 넣는다면 **보험료 비교 설명 + 계약자 확인서**를 준비했다.
- [ ] 청약 직전 **3개월 안에 일반심사 보험에 가입한 이력**이 있는지 확인했다(있으면 일반가입형 재심사 안내).
- [ ] 간편가입은 **2년 안에 질병 등으로 사망하면 50%만 지급**된다는 점을 고지했다.
- [ ] **가입나이**를 설계 시스템에서 다시 확인했다. 예: 메트 달러 경정기 일반 남 20~70세 / 간편 30~75세, 신한 세븐PLUS 2 일반 남 만15~63세·여 만15~68세 / 간편 남 30~57세·여 30~65세 (신한 가입나이 26.07)
- [ ] **상품 정식명칭**을 확인했다. 예: 메트 간편가입 경정기는 요약서 안에서 "Plus"가 붙은 이름과 안 붙은 이름이 섞여 있음
- [ ] 법인이 **설립 2년 미만**인지 확인했다. 회사별로 인수 제한이 있음 (신한 예: 가입금액 5억 이하 & 월납 300만 이하. 일부 보험사는 2년 미만 법인 경정기 미인수) [회사별 확인필요]
- [ ] 조인(분할) 계약이면 **원수사에 합산 인수 가능 여부**를 먼저 확인했다. "한쪽만 인수되면 분쟁"

### 1-2. 계약 전 알릴 의무(고지의무)
- [ ] 고지는 **청약서에 서면으로** 한다. 설계사에게 말로 한 것은 효력이 없다.
- [ ] 피보험자(대표)와 함께 질문을 하나씩 읽었다. 메모에 나온 핵심 확인 항목: **5년 이내 암 진단, 2년 이내 수술 또는 입원** (청약 준비 메모)
- [ ] 간편심사도 "병력이 나왔을 때 해소되셨습니까"까지 확인했다.
- [ ] 고지를 줄이거나 빼라고 권하지 않았다. 설계사가 고지 기회를 주지 않거나 부실고지를 권하면 회사는 해지를 못 하지만, 그 책임은 설계사에게 돌아온다. (약관 제15조)

### 1-3. 재정심사 서류
- [ ] 이 계약이 **소득서류가 필요한 구간인지** 확인했다(기계약 합산 금액, 회사 기준). 아래 4장 예시 참고.
- [ ] 고지소득이 **월납 보험료·직업과 앞뒤가 맞는지** 확인했다.
- [ ] 제출 대상이 아닌 서류를 **알아서 추가 제출하지 않았다.** "제출된 서류는 모두 검토 대상" (재정심사 26.07)
- [ ] 메트 경정기의 재정심사 기준(매출·순이익·자본 대비 배수, 업력, 당타사 합산 기준)은 **자료가 없다.** 원수사 언더라이팅팀에 직접 확인했다. (인수재정심사 csv: "보험사 언더라이팅팀 직접 확인 필요") **[확인필요]**

### 1-6. 설명 자료
- [ ] **실제 가입설계서**를 출력했다(비교자료·시뮬레이터 수치를 고객 자료로 쓰지 않는다).
- [ ] 설계서 1쪽 "보장성보험으로 … 저축·재테크 목적의 상품이 아닙니다" 문구를 함께 읽었다.
- [ ] 저해약 구간(3년 전 0%, 3~5년 50%)을 설명했다.
- [ ] 달러 상품이면 **환율 하락 시 원화 기준 손실 가능, 환전 비용**을 설명했다. "달러의 장점만 말하면 불완전판매가 됩니다."
- [ ] 세무 설명은 정정사항 문구로 했다. "100% 손금", "30% 비용처리" 같은 말은 쓰지 않았다. (세무사 검토 필요)
- [ ] 보험사 내부 교육용 자료를 캡처해 고객에게 보여 주지 않았다. "청약서 앞 상품설명 중심으로" (미팅프로세스 5-1)

## 3. 자주 하는 실수

| 실수 | 왜 문제인가 | 예방 |
| --- | --- | --- |
| 건강 이력을 말로만 듣고 청약서에 안 적음 | 구두 고지는 효력 없음, 보험금 분쟁 | 청약서에 서면 고지 |
| 고지소득을 보험료보다 낮게 적음 | 재정심사 거절·보류 | 월납 대비 소득 확인 |
| 직업과 맞지 않는 고소득 고지 | 신빙성 부족으로 심사 문제 | 직업·소득 일치 확인 |
| 요구하지 않은 재무서류를 셀프 제출 | 제출 서류는 모두 검토 대상 (예: 3년 연속 결손 재무제표) | 요구받은 서류만 제출 |
| 일반 가능자를 간편으로 넣고 비교 설명 누락 | 계약자 확인서 필수 사항 누락 | 비교 설명 + 확인서 |
| 피보험자 서면동의 누락 | 계약 무효 | 대표 자필 서명 확인 |
| 환급률·"원금 회복"으로 먼저 설득 | 저축 상품으로 오해, 민원·불완전판매 | 보장 목적 먼저, 완납 전제 |
| 달러 장점만 설명 | 불완전판매 | 환율 손실 가능성 고지 |
| 세무 효과 단정 ("100% 손금", "30% 비용처리") | 근거 없거나 해석 상반 | 정정사항 문구 사용 (세무사 검토 필요) |
| "절판"을 이유로 서둘러 청약 | 실제 사례: 서둘러 계약했으나 한 달 만에 청약취소 | 고객이 이해·준비된 뒤 청약 |
| 조인 계약 합산 인수 미확인 | 한쪽만 인수되면 분쟁 | 원수사 사전 확인 |
| 근거 없는 실무 메모를 그대로 따름 | 예: "원화고정납 기재하지 않기", "유해약상품은 설명 안 해도 됨" 메모는 근거 불명 | 원수사 지침으로 확인 |
| 계약자·피보험자 칸을 바꿔 기재 | 계약 구조가 달라져 세무 처리까지 바뀜 | 작성예시와 대조 |
| 법인인감 대신 사용인감 날인 | 서류 보완 요청 | 인감증명서와 대조 |

## 4. 심사 대비

### 4-1. 재정심사 기준 예시: 신한 세븐플러스 계열 (26.07, 7~8월 썸머 신계약 청약분)

**③ 주의사항 (NOT TO DO) 원문 요지**
1. 고지소득이 월납보험료 대비 부족 (예: 월납 100만원 가입인데 월소득 100만원 고지)
2. 소득서류 제출 대상이 아닌데 셀프 제출 (제출 서류는 모두 검토 대상, 예: 3년 연속 결손 재무제표 스캔)
