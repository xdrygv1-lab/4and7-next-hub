# 다가구·현금 보유 가족의 일반 증여·상속 설계

## 한 줄 정의

법인에 넣기 어려운 주택 위주 자산가에게 "팔 것 / 줄 것 / 지킬 것"으로 자산을 나누고, 매각 순서·시점·수증자 분산·특례를 조합하는 설계.
**요점**: "주택은 법인에 넣지 않습니다. 현물출자 이월과세 배제(조특법 §32① 단서), 법인의 주택 취득세 12%, 임대업 취득세 감면 배제가 겹칩니다." / 중과 대상 주택은 "'팔아서 현금으로 주는 것'이 가장 비쌉니다. 건물째 증여", 단 증여 취득세 12% 중과와 납부재원(개략 6억 이상) / 차익 작은 자산부터 매각 / 현금은 ①창업자금 특례 ②신규 가족법인 무이자 대여·단계적 채무면제 ③혼인공제·수증자 분산(아들 1인 20억 약 6.0억 vs 아들10·며느리 부5·모5 분산 약 3.9억) / 국세청 감정평가 사업 주거용 확대(추정시가와 5억 이상 또는 10% 이상 차이) / 상속받은 부동산 취득가액은 상속세 결정가액(소령 §163⑨) / 보험금 증여(§34): 계약·납입 모, 수령 아들 / 상속세 재원 보험은 "아들이 계약자·수익자, 부가 피보험자… 보험료를 아들 소득으로 내야 상속재산에서 빠집니다."
