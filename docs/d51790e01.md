# TheClassic 경영인정기보험 사업방법서 정리 (달러·원화)

> **한눈에** 약관에서 비어 있던 **전환 시점·금액 조건**을 사업방법서로 확인한 정리입니다. 법인 대표에게 경영인정기보험을 설명하며 종신·연금 전환을 말할 때 근거로 씁니다.
> 내부 참고용. 고객에게는 가입설계서·상품설명서 기준으로 안내.

## 핵심 조건 표
| 항목 | 내용 |
|---|---|
| 계약자 / 피보험자 | **법인** / 해당 법인 재직 **CEO, 등기임원** |
| 보험기간·납입 | **90세** 만기, 90세납(전기납), 월납 |
| 가입나이 | 일반: 남 **20~70세** / 여 원화 **22~70세**, 달러 **24~70세**. 간편: **30~75세** |
| 가입한도 | "회사가 정한 기준에 따라 제한될 수 있음" (수치 미기재) |
| 플러스보험기간 (달러형만) | 90세 연계약해당일부터 **5년**, 일시납. 만기 계약자적립액(대출 차감) 0 초과 시만 |
| 원화고정납입 (달러형) | 추가보험료: 1회 기본보험료 **50%** 이내, 총액 기본보험료 납입총액 **50%** 이내 |
| 감액완납 | 사업방법서 조항 없음. 약관 기준(**5년** 경과 후 회사 승낙)이 유일한 근거 |

## 전환 조건
| 구분 | 가능 시점 | 금액 조건 | 적용 기준 |
|---|---|---|---|
| **종신전환** | 전환 전 계약을 **7년 이상** 정상 유지 | 없음 | 기존 계약 전부 해지 시만. **전환시점 나이·기초율** |
| **연금전환** (공통) | 계약일부터 **7년** 경과 | 주계약 해약환급금 **1,000만원** 이상 | **가입 당시 기초서류** (장기간병 위험률만 전환 당시) |
| **달러연금전환** (달러형) | 계약일부터 **7년** 경과 | 주계약 해약환급금 **10,000달러** 이상 | 위와 같음 |
| **조기 계약전환** | 기본보험료 **36회** 이상 납입 | 최저가입금액 미달 시 추가납입 가능 | 사유 4가지 + 회사 승낙 |

조기 계약전환 사유와 서류: 폐업(폐업사실증명원), 3개월 이상 입원·요양(입·퇴원확인서 등), 대표이사 직위 변경(법인등기부등본), 최대주주 지위 변경(주주명부·주식등변동상황명세서)

## 이런 고객에게
- 7년 뒤 종신·연금으로 바꿔 쓰고 싶은 법인 대표
- 퇴임이나 지분 변동이 예정된 대표 (36회 이후 조기 전환 여지)
- 가입 당시 조건을 고정하고 싶은 대표 (연금전환은 가입 당시 기초서류 적용)

## 설명할 때 꼭 말할 것
- 종신전환은 **7년 이상 유지** 후, 연금전환은 **7년 경과 + 해약환급금 기준** 충족 시 가능
- ⚠ 종신전환은 전환 시점 나이·요율 적용이라 늦을수록 보험료 부담이 커집니다
- ⚠ 조기 계약전환 시 해약환급금이 가입 시 안내보다 적을 수 있습니다
- ⚠ 전환은 주계약 해약환급금 기준이라 전환 시점에 법인 해약환급금이 발생합니다. 세무 처리는 세무사 검토 사항

> "대표님, 7년 정상 유지하시면 종신이나 연금으로 바꿀 수 있는 조건이 사업방법서에 있습니다. 다만 회사 승낙과 금액 조건을 같이 보셔야 합니다."

## 자주 헷갈리는 점
| 헷갈리는 점 | 정리 |
|---|---|
| 종신·연금 전환 기준이 같다? | 종신은 **전환시점** 나이·기초율, 연금은 **가입 당시** 기초서류 |
| 3년이면 언제든 전환? | 조기 전환은 **4가지 사유**가 있을 때만, 회사 승낙 필요 |
| 간편가입은 누구나? | 일반심사 가능하면 보험료 비교 설명 + 계약자 확인서 필수. 3개월 내 일반심사보험으로 갈아타면 본 계약 무효 |

## 꼭 확인할 것
- [ ] 가입한도는 회사 기준 확인 (수치 미기재)
- [ ] 전환 가능 나이·연금 개시나이는 연금형태별로 확인
- [ ] 전환 시점 해약환급금 세무 처리는 세무사 검토 사항
- [ ] 퇴직금 지급 시점과 조기 전환 시점 맞춤 여부
- [ ] 청약 직전 3개월 내 일반심사보험 가입 이력
