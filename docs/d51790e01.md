## 3. 원화고정납입 (달러형)
- 원화환산납입서비스특약 부가 + 원화고정납입옵션 신청 시
- 원화고정납입용 추가보험료: 1회 기본보험료의 50% 이내, 총액 기본보험료 납입총액의 50% 이내
- 고정납초과보험료 자동인출 옵션 신청 가능

## 4. 간편가입형 관련
- 일반심사 가능한 피보험자면 보험료 비교 설명 + 계약자 확인서 필수
- 계약일 3개월 이내 일반심사보험으로 갈아타면 본 계약 무효, 납입보험료 반환
- 청약 직전 3개월 이내 일반심사보험 가입 이력 있으면 표준체 재심사로 일반가입형 안내

## 5. 감액완납
사업방법서에 별도 조항 없음 → 약관 기준(5년 경과 후 회사 승낙)이 유일한 근거.

## 6. 세무 상담 연결 포인트 (세법 확인필요)
- 종신전환·연금전환 모두 **주계약 해약환급금 기준으로 전환** → 전환 시점에 법인 해약환급금 발생. (세무 처리는 세무사 검토 사항)
- 종신전환은 **전환 시점 나이·요율** 적용 → 늦게 전환할수록 종신 보험료 부담 커짐. 대표 나이 고려해 7년차 전후 전환 타이밍 설계
- 연금전환은 **가입 당시 기초서류** 적용 → 가입 시점 조건이 고정되는 장점
- 대표 퇴임(대표이사 변경) 시 조기 계약전환(36회 이상) 가능 → 퇴직금 지급 시점과 맞춘 설계 여지
