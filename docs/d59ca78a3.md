# 2027 수수료 분급제 · 1200% 룰

근거 표기: 2026.1.14 보험업감독규정 개정안 기준

## 핵심 3가지
1. **1200% 룰 GA 확대 (2026.07~)**: 첫해 수수료 총액이 월보험료의 1,200% 이내. 관리자 OR·시책 포함.
2. **분급제 (2027.01~)**: 2027년부터 4년 분할, 2029년부터 7년 분할.
3. **1년차 선지급 축소**: 1차년도 선지급 한도 1,150% → 970%.

## 계산 공식
| 구분 | 1년차 수령 | 잔여 분급 |
|---|---|---|
| 시행 전 (~2026.12) | (1,200% − OR) × 본인 테이블 | 없음 (익월 집중) |
| 4년 분급 (2027~28) | (970% + 유지관리 1년 225% − OR) × 본인 테이블 | 36개월 분할 |
| 7년 분급 (2029~) | (970% + 유지관리 1년 120% − OR) × 본인 테이블 | 72개월 분할 |

- 7년 풀유지 시 총량: 4년 분급 약 +11%, 7년 분급 약 +28% (해지 시 잔여 수당 증발)
- 계산기 기본값: 관리자 총 OR 30%, 본인 지급률 70%

## 지점 운영 시사점
- 2026.12까지 체결분이 기존 구조 적용 → **연내 계약 집중 동기**
- 분급제 이후는 **유지율 = 소득**. 지점원 교육에서 해지 방지·사후관리 비중을 높여야 함
- 지점장 OR도 분급 대상이 되므로 지점 현금흐름 계획 필요
