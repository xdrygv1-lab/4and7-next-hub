# 가지급금 해소 소득화 플랜 (액면소각·급여배당·임원퇴직금)


## 한 줄 정의

- "대표자 가지급금 해소를 위한 장기적·합법적 소득화 방안"

## 대상 업체 신호

- 대상 신호: 재무상태표의 가지급금 잔액(사례 약 3억, 2023년 1.5억 → 2025년 10월 3.3억 증가), 보통예금 과다(11억대).

## 고객 니즈

- 문제 제기: "가지급금은 대표자가 회사 자금을 개인적으로 사용한 것으로 간주되어 세무조사 시 주요 점검 대상", "대표자는 인정이자 소득세 부담, 법인은 인정이자 법인세 부담으로 이중과세". 숫자: "3억 X 4.6% = 13백만원, 급여로 상환시 55%인 7.1백만원 파생비용", "13백만원 X 22% = 2.8백만원", "매년 약 천만원 세금 발생"

## 해결 구조 (세법 근거는 자료에 있는 그대로)

- 방향 4가지: "장기적·합법적 소득화 플랜(최대 4년)" / "자본정리를 통한 재무구조 개선(액면소각)" / "다양한 소득화 수단(급여·배당 14% 분리과세·퇴직금)" / "단계적 실행"

- 구조: 액면소각("주주가 출자 시 납입한 금액(액면가)과 동일한 금액으로 환급받는 구조로, 세법상 과세 이슈 없이", 사례 1,400주 × 10만원 = 1.4억 회수, 지분율 유지, 이사회 결의 등 상법 절차) → 급여·배당 혼합(연봉 1.6~2억 + 배당 2천 실효세율 17.68~20.45% 표) → 임원퇴직금(51세, 19년 후 퇴직 가정, 연봉 1.8억 × 2배수 → 예상퇴직금 8.97억, 퇴직소득세 1.29억, 실효세율 14.43%; 같은 금액을 급여로 받으면 45.72%, 배당 39.60%). "임원퇴직금, 실행을 위해서는 규정정비와 재원마련이 필요합니다."

- 로드맵: 1단계(올해) 액면소각·가지급금 일부상환 1.1억·급여구조 정비·배당정책·임원퇴직금 규정 / 2단계(내년) 급여+배당 시행, 퇴직금 적립 본격화 / 3단계(3~4년) 가지급금 전액 해소.

## 연계 보험상품과 연결 논리

- 보험 연결: 자료 본문엔 상품명 없음. "퇴직금 적립 본격화"의 재원 = 경정기·법인 종신 연결 지점 [연결은 정리자 해석].
