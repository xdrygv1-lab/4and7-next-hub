# 약관 정리: 전환특약 (종신전환·연금전환)

> **한눈에** TheClassic 경영인정기보험(달러·원화)에 붙는 종신전환·연금전환 특약약관을 정리했습니다. 법인 대표에게 "경정기를 나중에 종신이나 연금으로 바꿀 수 있나"를 설명할 때 씁니다. 전환 가능 시점·나이·금액 한도는 특약약관에 없고 사업방법서 사항이라 회사 확인이 필요합니다.
> 내부 참고용. 고객에게는 가입설계서·상품설명서 기준으로 안내.

## 경정기에 붙는 전환특약
| 특약 | 원화 경정기 | 달러 경정기 |
|---|---|---|
| 무배당 종신전환특약 (간편형은 간편가입형) | **자동부가** | **자동부가** |
| 무배당 신연금전환특약_(가입시점) | **자동부가** | **자동부가** |
| 무배당 달러연금전환특약_(가입시점) | 없음 | **자동부가** |
| 무배당 연금전환특약_(전환시점) | 없음 | 없음 |

주계약의 "조기 계약전환 옵션"(36회 이상, 4가지 사유)은 이 특약들과 별개 제도입니다.

## 핵심 조건 표
| 항목 | 종신전환 | 연금전환 (가입시점, 원화·달러) |
|---|---|---|
| 전환 가능 시점·나이·한도 | 약관에 없음 | 약관에 없음 |
| 기존 계약 처리 | **전부 해지**만 가능 (일부 해지·감액 전환 불가) | 해약환급금 **전부 또는 일부** 일시납 |
| 전환 후 보장 | 종신 사망보험금(특약보험가입금액) | 종신연금형(개인·부부·장기간병), 상속연금형, 확정연금형 |
| 적용 기준 | 가입나이는 전환일 기준 보험나이 | **경정기 가입 당시** 기초서류 (장기간병 위험률만 전환 당시) |
| 최저보증이율 | 해당 없음 | 경정기 계약일부터 5년 이내 **1.0%**, 이후 **0.7%** |
| 고지·심사 | 고지의무 조항 있음, 무심사 문구 없음 | 고지의무 있음 |
| 대출 | 미상환 대출은 특약으로 이전 (연체이자는 상환) | 이전 규정 없음 |
| 중도인출 | 해당 없음 | 해약환급금 **50%** 범위, 연 **12회** |

달러연금전환은 기준통화가 **달러**이고, 최소 추가납입 **100달러**, 외국환거래법에 따라 대출이 제한될 수 있습니다.

## 이런 고객에게
- 경정기 가입 후 대표 은퇴 시점에 종신 보장이나 연금으로 바꾸고 싶은 법인
- 가입 당시 연금 기초서류(연금사망률 등)를 고정해 두고 싶은 대표
- 달러 자산을 연금으로 이어 가고 싶은 대표 (달러형만)

## 설명할 때 꼭 말할 것
- ⚠ "몇 년 뒤 종신으로 바꿀 수 있다"는 말은 사업방법서·회사 전환기준을 확인한 뒤에만 합니다
- ⚠ 종신전환은 경정기를 **전부 해지**하고 해약환급금을 일시납으로 넣는 구조. 저해약형이라 전환 시점에 따라 종신 가입금액이 크게 달라집니다
- ⚠ 종신전환은 청약을 철회해도 **경정기로 돌아가지 않습니다**
- ⚠ 종신연금형을 고르면 연금개시 후 **해지 불가**. 법인 자금이 묶이므로 상속연금형·확정연금형과 비교 설명
- ⚠ 전환 시 해약환급금이 발생하는 구조입니다. 세무 처리는 세무사 검토 사항

> "대표님, 이 계약에는 종신과 연금으로 바꾸는 특약이 기본으로 붙어 있습니다. 다만 바꾸는 시점과 조건은 회사 기준으로 따로 확인해 드리겠습니다."

## 자주 헷갈리는 점
| 헷갈리는 점 | 정리 |
|---|---|
| 가입시점형이 항상 유리? | 기초서류는 가입 당시로 고정되지만, 최저보증이율 5년은 **경정기 계약일**부터 세서 5년 후 전환하면 처음부터 **0.7%** |
| 종신전환은 무심사? | 약관에 무심사 문구 없음. 고지의무 조항 그대로 |
| 간편형 종신전환은 조건이 다르다? | 약관 조문은 일반형과 동일. 간편 고지 기준이 전환 시 적용되는지는 회사 확인 필요 |
| 법인 계약자도 전환 가능? | 제한·허용 문구 모두 없음. 신청 주체는 "계약자" |

## 꼭 확인할 것
- [ ] 전환 가능 경과년수·나이·금액 한도·최소 전환금액을 회사에 확인
- [ ] 간편형 고지 기준이 전환 시 그대로 적용되는지 (확인 필요)
- [ ] 연금전환 일부 전환 시 나머지 해약환급금 처리 (약관에 없음)
- [ ] 달러 경정기에서 원화 연금으로 전환 시 환산 방법 (확인 필요)
- [ ] 연금 수익자 지정과 명의변경 순서
- [ ] 전환 시 세무 처리는 세무사 검토 사항
