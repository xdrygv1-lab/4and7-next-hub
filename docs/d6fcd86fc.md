# 약관정리: 전환특약 (종신전환·연금전환), TheClassic 경영인정기보험(달러·원화) 적용

> 용도: 법인 대표 대상 "경정기 → 종신 전환", "경정기 → 연금 전환" 상담.
> 핵심 전제: 다섯 개 특약약관 모두 **전환 가능 경과년수, 피보험자 나이 제한, 전환 가능 금액 한도, 연금개시 나이 범위, 최소 전환금액(원·달러 금액)을 적지 않습니다.** 이 항목들은 각 특약의 사업방법서(약관 밖 기초서류) 사항이므로, 아래에서 "약관에 없음"으로 표기했습니다. 상담 전에 회사로 확인해야 합니다.

## 0. 경정기에 실제로 붙는 전환특약 (적용 여부 확인 결과)

| 특약 | 원화 경정기 (일반 / 간편) | 달러 경정기 (일반 / 간편) | 근거 |
|---|---|---|---|
| 무배당 종신전환특약 | O (자동부가) / 간편가입형 특약으로 부가 | O (자동부가) / 간편가입형 특약으로 부가 | 상품요약서 상품구성(자동부가특약), 주계약 약관 특약 색인 "(무)종신전환특약 별도약관" |
| 무배당 종신전환특약(간편가입형) | 간편가입 경정기Plus에 자동부가 | 간편가입 달러경정기Plus에 자동부가 | 상품요약서 상품구성 |
| 무배당 신연금전환특약_(가입시점) | O (자동부가) | O (자동부가) | 상품요약서, 특약 색인 |
| 무배당 달러연금전환특약_(가입시점) | X | O (자동부가) | 상품요약서, 달러형 특약 색인 |
| 무배당 연금전환특약_(전환시점) | X | X | 경정기 상품요약서·특약 색인 어디에도 없음 |

- 결론: **종신전환특약은 경정기(달러·원화 모두)에 자동부가특약으로 붙어 있습니다.** 공시실 "특약보기" 목록에 빠져 있었을 뿐, 상품요약서 상품구성과 주계약 약관 특약 색인 두 곳에서 확인됩니다.
- 다만 종신전환특약 약관 본문에는 "적용 대상 주계약"이나 "전환 가능 상품명"이 적혀 있지 않습니다. 약관은 "이미 체결되어 있는 하나 이상의 유효한 계약(부가된 특약 포함)에 부가"한다고만 규정합니다(종신전환특약 제13조 ①). 적용 여부는 약관 본문이 아니라 상품요약서·특약 색인으로 판단한 것입니다.
- 연금전환특약_(전환시점)은 경정기에 부가되지 않습니다. 비교 참고용으로만 3장에 정리합니다. 이 특약 제7조 ②가 "연금보험에서 이 특약으로 전환하는 경우"를 따로 규정하는 점에서 다른 상품군용 특약으로 보입니다(추정, 회사 확인필요).
- 주계약의 "조기 계약전환 옵션"(원화 제44조, 달러 제45조)은 이 특약들과 별개 제도입니다.

## 2. 종신전환특약 (일반·간편)

### 2-1. 조건별 정리

| 항목 | 약관 내용 | 조항 |
|---|---|---|
| 전환 가능 시점 (경과년수) | 약관에 없음. "회사가 정한 절차에 따라 전환을 신청"할 수 있다고만 규정 | 제15조 ① |
| 피보험자 나이 제한 | 구체 나이 약관에 없음. "특약에서 정한 피보험자의 나이"에 미달·초과 시 특약 무효라는 규정만 있음 | 제18조 ① 3호 |
| 가입나이 기준 | 보험나이(계약일 현재 만나이, 6개월 미만 버림·6개월 이상 1년). 이 특약의 계약일 = 보험료를 받은 날(보장개시일) = 전환일 | 제20조 ①②, 제22조 ①, 제15조 ② |
| 전환 가능 금액 (주계약 가입금액 대비 한도) | 약관에 없음 | |
| 전환 후 보장 | 피보험자가 보험기간(종신) 중 사망 시 사망보험금(특약보험가입금액) 지급 | 제2조 ① |
| 보험료 산정 방식 | 전환전계약의 해약환급금 전부를 일시에 납입. 보험료 납입일부터 보장개시 | 제21조 ① |
| 보험료 산정 기준 나이 | 약관에 "전환시점 나이로 산정"이라는 직접 문구는 없음. 다만 가입나이는 이 특약 계약일(=전환일) 기준 보험나이로 정함 | 제20조, 제22조 ① |
| 보험계약대출 처리 | 대출 원금·이자를 갚지 않고 전환하면 특약의 대출원금으로 이전. 이자 연체가 있으면 전환 신청 시 연체이자 전액 상환 | 제21조 ② |
| 고지·심사 | 특약 체결은 계약자의 청약과 회사의 승낙으로 이루어짐. 계약 전 알릴 의무(고지의무) 조항이 그대로 있음(진단계약 언급 포함). 심사 면제 문구는 없음 | 제13조 ②, 제12조 ① |
| 고지의무 위반 해지 제한 | 보장개시일부터 사고 없이 2년(진단계약 질병 1년), 계약 체결일부터 3년 경과 등 | 제12조 ② |
| 기존 계약 처리 | 전환전계약은 특약 보장개시일(전환일)부터 효력 없음. 전부 해지만 가능하고 일부 해지·일부 감액 전환 불가 | 제15조 ②③, 제21조 ① |
| 해약환급금 처리 (유지형/해지형 구분) | 유지형·해지형 구분 약관에 없음. 해약환급금 전부가 이 특약의 일시납 보험료로 들어감(현금 수령 구조 아님) | 제21조 ① |
| 계약자·피보험자 동일 요건 | 약관에 없음. 종신전환특약에는 피보험자 범위 조항 자체가 없음(연금전환특약과 다름) | |
| 타인의 사망 계약 서면동의 | 타인의 사망을 지급사유로 하는 계약은 특약 체결 시까지 피보험자 서면(전자서명 포함) 동의 필요. 없으면 무효 | 제18조 ① 1호 |
| 청약 철회 | 보험증권 받은 날부터 15일 이내(청약일부터 30일 초과 시 불가). **철회해도 전환전계약으로 환원하지 않음** | 제14조 ①④ |
| 전환전계약으로 환원 | (1) 전환 전후 비교 전환안내서 미제공 또는 중요내용 미설명으로 계약자가 특약 취소, (2) 전환일 전 원인으로 특약 보험금 부지급(고지의무 위반 제외) 시 환원. 보험료 차액 정산 | 제16조 |
| 환원 불가 | 이 특약 보험금이 이미 지급된 경우 | 제17조 |
| 계약내용 변경 | 보험가입금액, 계약자 등은 회사 승낙으로 변경. 감액분은 해지로 보고 해약환급금 지급 | 제19조 ①③ |
| 보험계약대출 | 이 특약 해약환급금 범위 내 | 제26조 ① |
| 전환전계약 약관 준용 | 특약에 없는 사항은 전환전계약 약관을 따르되, 보험계약대출·계약내용 변경 조항은 준용하지 않음 | 제29조 ①② |
| 배당 | 무배당 | 제27조 |

### 2-2. 간편가입형과 일반형의 차이

| 항목 | 결과 |
|---|---|
| 약관 문구 | 공백·쪽 표기를 제거하고 전문 대조한 결과, 특약명 "(간편가입형)" 표기와 문장부호 1곳 외에 **조문 내용이 동일**합니다. 조항 번호(제1조~제29조)도 같습니다. |
| 고지항목 축소, 인수기준, 보험료 차이 | 약관에 없음 |
| 실무 의미 | 간편가입 경정기Plus에는 간편가입형 종신전환특약이 붙습니다. 간편형 고지 기준이 전환 시 그대로 적용되는지는 약관으로 확인되지 않으므로 회사 확인필요 |

| 보험계약대출 | 연금개시 전 보험기간 중 해약환급금 범위 내 (제18조 ①) | 동일, 외국환거래법에 따른 제한 가능 (제20조 ①) | 전환전 계약 대출 조항 준용 안 함 (제15조 ②) |

### 3-3. 가입시점 vs 전환시점

| 구분 | 가입시점형 (경정기에 붙는 것) | 전환시점형 (경정기 미부가) |
|---|---|---|
| 기초서류 | 경정기 가입 당시 연금 기초서류 고정 (장기간병 위험률만 전환 당시) | 전환할 때의 기초서류 |
| 최저보증이율 기산점 | 경정기 계약일. 경정기 가입 후 5년이 지나 전환하면 처음부터 0.7% 구간 | 연금전환일 |
| 연금개시 | 개시나이 선택, 거치 가능 + 추가납입·중도인출 | 전환일 즉시 개시 |

## 4. 법인계약 관점 체크

| 항목 | 약관 내용 | 조항 / 비고 |
|---|---|---|
| 계약자가 법인일 때 전환 가능 여부 | 법인 계약자를 제한하거나 허용하는 문구 모두 약관에 없음. 전환 신청 주체는 "계약자"로만 규정 | 종신 제15조 ①, 신연금 제11조 ①, 달러 제13조 ① |
| 피보험자 | 연금전환: 전환전 계약의 피보험자(대표)가 그대로 피보험자. 종신전환: 피보험자 범위 조항 없음 | 신연금 제12조 ①, 달러 제14조 ①, 전환시점 제9조 ① |
| 연금 수령자 | 연금개시 전 사망 시 지급금은 계약자에게 지급(달러 제13조 ⑤ 지급대상). 연금 수익자 지정 특칙 없음. 법인 계약자 상태로 연금전환하면 연금 수령 구조는 수익자 지정에 따름 | 수익자 변경은 계약자·피보험자가 다르면 피보험자 서면동의 필요 (종신 제19조 ④, 신연금 제14조 ⑥, 달러 제16조 ⑥) |
| 부부연금형 | 종피보험자는 주피보험자(대표)의 배우자 | 신연금 제12조 ①, 달러 제14조 ① |
| 명의변경과 전환의 순서 | 순서를 정한 조항 약관에 없음. 전환 후에도 특약에서 계약자 변경은 회사 승낙 사항으로 가능 | 종신 제19조 ① 2호, 신연금 제14조 ① 4호, 달러 제16조 ① 4호. 주계약 단계 계약자 변경은 주계약 정리 파일 참조 |
| 전환 시 해약환급금 발생 여부 | 세 특약 모두 전환전계약의 **해약환급금을 전환 후 계약의 일시납 보험료로 납입**하고 전환전계약은 효력을 잃는 구조. 종신전환은 전부 해지 전제(제15조 ③), 연금전환은 전부 또는 일부 | 세무 검토 사항 |
| 연금전환 일부 전환 시 잔여분 | "전부 또는 일부" 납입 가능하나, 일부만 넣을 때 나머지 해약환급금 처리(현금 지급 여부)는 약관에 없음 | 세무 검토 사항 |
| 보험계약대출이 있는 경우 | 종신전환: 대출이 특약으로 이전(이자 연체분은 상환). 연금전환: 약관에 이전 규정 없음 | 종신 제21조 ② |

## 5. 실무 체크포인트

1. 경정기에는 종신전환특약(간편형은 간편가입형)과 신연금전환특약_(가입시점)이 자동부가되어 있고, 달러형은 달러연금전환특약_(가입시점)이 추가로 붙습니다. 연금전환특약_(전환시점)은 경정기에 없습니다.
2. 전환 가능 경과년수, 나이, 금액 한도, 최소 전환금액은 다섯 개 약관 어디에도 없습니다. "몇 년 뒤 종신으로 바꿀 수 있다"는 설명은 사업방법서·회사 전환기준으로 확인한 뒤에만 써야 합니다.
3. 종신전환은 경정기를 **전부 해지**하고 해약환급금 전부를 일시납으로 넣는 구조입니다(제15조 ③, 제21조 ①). 저해약환급금형 경정기는 초기 해약환급금이 적으므로 전환 시점에 따라 종신 가입금액이 크게 달라집니다.
4. 종신전환특약은 청약·승낙으로 체결되고 고지의무 조항이 그대로 있습니다(제12조, 제13조 ②). 무심사 전환이라는 문구는 약관에 없습니다. 청약 철회해도 경정기로 돌아가지 않습니다(제14조 ④).
5. 가입시점 연금전환의 최저보증이율 5년 구간은 경정기 계약일부터 셉니다(신연금 제7조 ①). 경정기 가입 5년 후 전환하면 최저보증은 연복리 0.7%입니다. 대신 경정기 가입 당시 기초서류(연금사망률 등)가 고정됩니다(제8조 ①).
6. 종신연금형을 고르면 연금개시 후 해지할 수 없습니다(신연금 제16조 ①, 달러 제18조 ①). 법인 자금을 묶는 구조이므로 상속연금형·확정연금형과 비교해 설명합니다.
7. 세무 처리(비용처리·손금·익금 등)는 세무사 검토 사항입니다.
