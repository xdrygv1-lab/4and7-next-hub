# 경영인정기보험·단기납종신 비교 시뮬레이션

> **한눈에** 메트라이프 경영인정기보험과 단기납종신이 타사 대비 어디쯤인지 10년 환급률과 순비용으로 비교했습니다. 대표에게 상품 선택 근거를 설명할 때 씁니다. 전제: 환율 **1,400원/달러**, 가입금액 **1억원**(달러형 **$10만**), 90세 만기 전기납.
> 내부 참고용. 고객에게는 가입설계서·상품설명서 기준으로 안내.

## 3줄 정리
1. 메트 **달러** 경정기는 40~60세 일반심사에서 꾸준히 **2위**(40세 10년 **94.9%**). 1위 푸본현대(95.8%)와 차이는 **0.9%p**.
2. 메트 **원화** 경정기는 환급률 하위권(9위)이지만 월보험료는 최저(1억 기준 **36.7만**).
3. 단기납종신은 메트 **달러 백만종**이 전 조건 1위(10년 **117.8~124.9%**). 단, 환율 리스크 설명 필수.
