# 출시 예정 상품 검토 메모: 변액 경영인정기 (10/20 출시 예정)

> **한눈에** 10월 20일 출시 예정인 변액형 경영인정기 상품에 대해 개발팀이 미리 짚은 점입니다. 상품 교육 자료를 본 1차 의견이라, 출시 후 사업방법서와 설계서로 다시 확인해요. (확인 필요)

## 기존 경영인정기와 다른 점

| 항목 | 기존 경영인정기 | 이번 변액형 (1차 확인) |
|---|---|---|
| 만기 해지환급금 | 90세 만기에 0원 | 90세에도 환급률이 높게 남는 설계로 보임 (확인 필요) |
| 사망보장 | 만기에 끝남 | 만기 뒤 일정 기간 더 보장되는 구조로 보임 (확인 필요) |
| 감액완납 | 상품별 있음 | 없는 것으로 보임 (확인 필요) |
| 종신 전환 | 상품별 있음 | 있으나 활용도 검토 필요 |

## 꼭 짚을 점

- ⚠ **비용 처리**: 만기 환급금이 0원이 되지 않는 구조라, 기존 경영인정기처럼 보험료를 비용으로 보기 어려울 수 있어요. 세무 처리는 세무사 검토 사항입니다.
- ⚠ **전환 시 세금**: 종신 전환 때 그동안 비용으로 본 금액이 한꺼번에 이익으로 잡힐 수 있어요. 전환을 전제로 제안하기 전에 꼭 계산해 보세요. (세무사 검토)
- ⚠ **변액 상품**: 수익률에 따라 결과가 달라지고, 법인 계약은 예금자보호 대상이 아니에요.

## 꼭 확인할 것
- [ ] 출시 후 사업방법서로 만기 환급금, 보장 기간, 감액완납 여부 확인
- [ ] 비용 처리와 전환 시 과세 (세무사 검토)
- [ ] 기존 경영인정기와 같은 조건으로 비교 계산
- [ ] 변액 위험 설명 자료 준비
