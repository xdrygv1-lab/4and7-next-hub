# 초과배당(상증법 제41조의2)·차등배당


## 한 줄 정의

지분 정리 후 최대주주(부모)가 배당을 포기하거나 불균등 배당을 해 자녀·가족법인이 지분율보다 많은 배당을 받게 하는 이익 이전 보조수단.

## 해결 구조 (세법 근거는 자료에 있는 그대로)

**해결 구조·근거**

2021.12.21 개정으로 "(초과배당 − 소득세상당액) 증여" 후 실제 소득세로 정산하는 구조 → "과거식 '1억 한도 비과세' 단순설명 불가". 특정법인(가족법인)이 받는 초과배당은 §45의5 무상제공 거래로도 과세 가능(2024.10.31 개정 집행기준, 2025 자본거래 유형 신설). 실행 요건: 배당가능이익·정관상 차등배당 근거·주주총회 절차. 가족법인이 받는 배당은 수입배당금 익금불산입(20~50% 지분 80%, 50% 이상 100%)으로 재원화 유리(내부검토보고서). 개인 자녀는 "주주별 연 2천만 이하 분리과세(14%+지방)"로 관리.

**포지셔닝**: "초과배당은 메인 구조가 아니라, 지분 정리 후 주식취득 속도를 높이는 보조수단입니다."(1차미팅 v4). 협업 세무사 K: "초과배당은 장기적으로 설계가 필요한 부분이라 처음부터 전면에 두기에는 조금 부담이 있어 보입니다." 썰매장은 균등배당으로 자녀 25% 지분에 "매년 예를 들어서 2천만 원씩은… 되게 합법적인 증여 수단"(단장).
