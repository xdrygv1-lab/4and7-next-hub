# 가업승계·가업상속공제·증여특례·창업자금 특례


> 이 컨셉은 원 자료가 얇아 템플릿 항목(한 줄 정의, 대상 업체 신호, 고객 니즈, 해결 구조, 연계 보험, AP 질문, 제안 화법, 반론과 대응, 주의사항, 필요 자료)으로 나누지 않고 자료에 있는 내용만 요약함. 비어 있는 항목은 자료에 없음.

## 자료 요약

- 가업상속공제: "가업 상속 공제라는 파워풀한 제도", 다만 상속인이 이후 양도 시 피상속인 취득가액 적용 → 과세이연 성격, 부동산임대업 등 불가 업종, 업무무관자산 과다 시 실효성 저하. 고객 반론 "가업 상속 공제 이런 거 있던데… 600억까지 세금 안 나온다던데" 대응: 업종 불가 또는 자산 정리 필요를 설명하고, 원하면 과세이연 효과를 설명.
- 단장 법인전환 강의 녹취(세일즈연구소 25.02.03): 나이 든 대표는 절세보다 승계로 법인전환을 설득. 개인사업자는 가업상속공제 범위가 사업용 자산으로 좁고 법인은 포괄적이라는 취지, 증여특례는 법인만 가능. 잉여금 출구(청산·배당·상속증여·공제·이익소각)는 예고만 하고 다음 컨설팅으로 넘김. 순이익 3억 대표를 늦게 만나 결산이 6.5억이 된 타이밍 상실 사례. [일반지식, 확인필요: 가업상속공제는 법인도 사업무관자산 비율만큼 제외]
- 가업승계 증여세 과세특례: "가업승계 증여세 과세특례는 법인 지분에 한하여 가능" → 개인 부동산임대·사업을 법인전환해야 특례 대상이 된다는 설득 논리. 슬라이드: 순자산 50억 법인전환 후 "가/승/증/특 50억 Tax 4억(납부유예) * 23년 세법개정안 기준" [구버전 의심, 현행 한도·세율·납부유예 요건 확인필요] (기업의별 현물출자 강의 2022).
- 창업자금 증여특례(조특법 §30의5): 부 60세 이상 요건, "현금 10억 증여 시 (10억에서 5억 차감) × 10% = 5천만원", 일반 증여와 합산하지 않음, 상속 때는 기간 무관 합산·정산, 업종 제한(§6③), 2년 내 창업, 4년 내 사용, 10년 사후관리, 기존 사업 승계·자산 인수는 창업 아님, 폐업 시 추징+이자(가족 C 검토요약).
- 혼인공제: 혼인신고일 전후 2년 이내 직계존속 증여분 1억, 기본공제와 별개, 출산공제와 통합 한도 1억, 혼인 못 하면 수정신고와 이자상당액(가족 C 검토요약).
- 판독 불가 강의: 교육과정이종헌 회계사 "가업상속 & 증여특례 실전 Case Study", 결산특강 박제율 "가업승계 제도 검토", 조태진 변호사 "성년후견·유류분" 강의는 텍스트 추출 실패. 유류분·성년후견은 가족 C 검토요약에서 "조모(87세)의 의사능력에 문제가 생기면 성년후견 절차로 매각이 장기간 지연될 수 있습니다", 상가빌딩 건 "유류분·가족 합의 리스크는 별도" 정도만 언급.
