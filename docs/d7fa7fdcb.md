## 2. 나이·목적별 상품 선택 흐름

> 내부 판단용 흐름입니다. 고객에게는 상품명보다 니즈 질문을 먼저 합니다(화법_반론처리 7장: AP에서 상품명 언급 금지).

```
[1] 계약자가 법인인가, 개인인가?
     ├─ 개인사업자·개인 → 경정기 아님 (개인사업자 본인 정기보험료 필요경비 불산입, 서면법규과-1539)
     │                    → [3] 종신 쪽으로
     └─ 법인 → [2]

[2] 법인 대표: 나이와 목적
     ├─ 40대, 법인세 부담 + 퇴직재원 + 유고 대비
     │     → The Classic 달러 (40세 일반 10년 94.9%, 12개 중 2위)
     │       또는 원화 (보험료 최저, 같은 예산으로 보장 최대)
     ├─ 50대 ~ 60대 초반
     │     → 경정기도 가능하나 환급률 하락 (달러 일반 10년: 50세 93.3%, 60세 87.2%)
     │     → 환급률 100% 미만이 불만이면 종신 단기납(백만인) 또는
     │       타사 원금형 종신(제로백 등, 비교 참고만) 비교
     ├─ 70세 이상
     │     → 경정기 10년 환급률 60%대 → 종신·상속형 검토 (3년내, 모두의상속)
     └─ 업력 짧은 신설법인 → 메트 경정기 가입 가능 여부 원수사 확인 [확인필요]

[3] 종신: 목적별
     ├─ 목적자금 (자녀 유학·은퇴·달러), 사망보장 니즈 작음, 40대~50대 초반
     │     → 백만인 달러 7년납 또는 5년납 ("7+3": 7년 납입 후 10년 시점)
     ├─ 환율이 싫은 목적자금 → 백만인 원화
     ├─ 상속재원, 레버리지 최대, 해지 가능성 없음
     │     ├─ 오래 내기 싫다 → 3년내고만족 달러종신
     │     └─ 은퇴 시점에 맞춰 납입 종료 + 건강특약 → 모두의 달러종신
     ├─ 상속재원 + 추가납입 통로 + 원금손실 감수 → 변액유니버셜 모두의상속종신
     └─ 고령·유병 (간편)
           ├─ 76~80세 → 3년내 간편 (30~80세)
           ├─ 75세까지 → 백만인 간편 5년납 (30~75세), 모두의상속 간편 5년납·80세납 (최대 75세)
           └─ 공통: 간편은 가입 후 2년 미만 재해 이외 사망 시 50%, 보험료 높음
```

## 3. 공통 주의 (모든 상품)

1. **세무 문구**: 경정기·종신 모두 "100% 손금", "N% 비용처리" 금지. 상품별 FAQ 6장 문구만 사용
2. **확정 수익·원금 보장 표현 금지**: 이 폴더의 어떤 상품도 해약환급금 원금을 약관상 보장하지 않습니다. 변액(모두의상속)은 해약환급금 최저보증이 없다고 명시되어 있습니다
3. **변액**: 수익률 변동, 원금손실 가능, 법인 계약자·납부자면 예금자보호 대상 아님 (요약_변액유니버셜모두의상속종신 8장)
4. **달러 상품**: 환율 하락 시 원화 손실 가능, 손실은 계약자 귀속 (약관정리_TheClassic달러경영인정기 9장)
5. **무해약·저해약**: 납입 중 해지 손실을 먼저 설명. 해지를 전제로 판매하면 불완전판매
6. **상속세 최고세율**: "현행 50% [최신 세법 확인]"
7. **자료 사용**: 보험사 내부 교육용 자료, 외부 Q&A 자료("모집인 교육용, 고객 안내용 사용 불가") 자료를 고객에게 보여주지 않음
8. **고객 실명**: 자료·강의에 실제 고객 이름을 쓰지 않음 (화법_반론처리 7장)
