# 경영인정기보험(법인 계약) 예규·판례 정리 (2026-10)

* 작성일: 2026-10-04
* 대상: 계약자·수익자 법인, 피보험자 대표이사(임원)인 만기환급금 없는 정기보험(경정기) 및 유사 종신보험
* 표기 원칙: 문서번호와 일자는 검색 결과·본문에 표시된 그대로 적었다.은 해당 회신 본문 안에서 인용된 문서로, 원문을 따로 열어보지는 않은 것이다.은 검색 결과 제목만 확인한 것이다.
* 주의: 국세청 질의회신은 법적 구속력이 없고 개별 사실관계 전제다. 실제 적용 전 원문 재확인 필요.

## A. 만기환급금 없는 정기보험 보험료: 전액 손금인가, 해약환급금 상당액 자산계상인가

### 국세청 입장 변화 요약
1. 2000~2005: 손금불산입(대표 부담 보험료, 상여처분) 입장
2. 2006~2013: "만기환급금 상당액은 자산, 나머지는 보험기간 경과에 따라 손금" 원칙 정립
3. 2013.10: 정년이 정해진 경우 "정년퇴직시 해약환급금 상당액"은 자산계상(사전답변)
4. 2015.4 기재부 해석 이후, 2018년부터 "퇴직시점 예측 불가로 해지환급금 산정 불가 + 만기환급금 없음이면 납입보험료를 보험기간 경과에 따라 손금" 으로 정리. 2020년 경영인정기보험 실명 사례, 2026년 종신보험 사전답변까지 같은 결론 유지
5. 상반: 조세심판원 국심2006서3194(2007.04.04)는 "각 과세기간 종료일 현재 해약환급금 상당액"을 자산으로 보았다

**상반 해석 명시**: (1) 소득구분: 서면1팀-309·소득세과-3449는 근로소득, 기재부-109·서면-2016-법령해석소득-3158·서면-2022-원천-3587은 퇴직소득(한도초과분 근로소득). 차이는 "현실적 퇴직" 여부로 정리됨. (2) 평가액: 2004 해석은 기불입 보험료상당액, 상증세 해석(기재부-929)은 해지환급금, 증여세 판례는 1심 해지환급금, 2심 납입보험료로 엇갈림. 법인세·소득세 목적의 경정기 명의변경 평가액을 명시한 해석은 이번 검색에서 확인되지 않음.

## F. 외화(달러) 보험계약의 환산손익

| 문서번호·일자 | 결론 요지 | 경정기 시사점 |
|---|---|---|
| 서면-2020-법령해석소득-1222 (2021.03.19) | 기재부 금융세제과-84(2021.3.8) 참고. 외화 저축성보험 보험차익은 외화 지급보험금에서 외화 납입보험료를 뺀 외화차익을 보험금 지급일 환율로 환산(개인 이자소득) | 개인 단계(명의이전 후) 과세 시 참고. 법인 보유분에 직접 적용되는 해석 아님 |
| 법인세과-666 (2009.06.04) | 보험회사의 외화보험 책임준비금은 사업연도 종료일 기준환율로 환산 | 보험회사 측 해석. 계약자 법인과 무관 |
| 서면-2017-법인-3219 (2018.02.27) | 일반법인이 기말환율 평가방법을 신고했으면 화폐성 외화자산·부채 환산차손익을 익금·손금 산입 | 외화보험 해약환급금(자산계상분)을 화폐성 외화자산으로 볼지에 대한 해석은 없음 |
| 법인세과-408 (2009.04.08) | 금융회사 외 법인의 외화자산·부채 평가 규정 적용 시기 | 일반 원칙 |

* 일반법인이 보유한 외화(달러) 경영인정기보험·종신보험의 환산손익 처리를 직접 다룬 해석: **검색 결과 없음**(사용 검색어: "외화보험", "외화 보험", "외화자산 평가").
* 실무 판단: 국세청 해석대로 전액 손금(자산 0) 처리하면 환산 대상 장부가액이 없으므로, 해지 시 원화 수령액 전액이 익금이 된다(B 참조). 자산계상분이 있을 때만 환산 문제가 생긴다(추가확인 필요).

## G. "과세이연" 구조에 대한 과세관청 시각, 해지 후 종신보험 전환

| 문서번호·일자 | 결론 요지 | 경정기 시사점 |
|---|---|---|
| 서면-2020-법인-0953 (2020.08.28) | 사실관계에 "보험료 손금 + 해지환급금 상여 손금 = 이중 비용" 광고가 명시됨. 국세청은 손익귀속 원칙(납입 시 손금, 해지 시 익금)을 재확인하고 상여는 급여지급기준 내에서만 손금이라고 답함 | 구조 자체를 부인하지는 않았으나, 해지 시 익금 전액 과세와 상여 한도 통제를 전제로 함. 영업 화법에서 "세금이 없어진다"는 표현은 부적절, "이연"으로 설명해야 함 |
| 서면-2019-법인-3522 (2020.08.28) | 감액완납 시 해약환급금 상당액은 변경일 익금, 잔여기간 손금 | 계약 변경(감액, 감액완납, 전환)도 해약환급금 발생 시점에 익금 인식 요구 가능 |
| 서면-2023-법규법인-1077 (2023.11.28) | 명의변경 후 대표 해지 시 법인 처리 없음 | 법인 단계 과세는 명의변경 시점에 끝나야 함(이연 종료 시점) |
| 특약에 따라 다른 저축성보험으로 전환하는 경우 최초 보험료 납입일의 기산 (2009.06.02) | 개인 저축성보험 전환 시 납입일 기산 문제 | 법인 경정기 전환과 직접 관련 없음 |

* 정기보험 해지 후(또는 전환특약으로) 종신보험 전환 시 법인세 처리를 직접 다룬 해석·심판례·판례: **검색 결과 없음**(사용 검색어: "보험 전환", "감액완납", "종신보험", "해약환급금", "보험계약", "계약자 변경 보험").
* 유추: 전환 시 기존 계약의 해약환급금(또는 전환에 충당되는 적립금)은 서면-2019-법인-3522 논리상 전환일 익금, 새 종신보험은 다시 A의 원칙(퇴직기한 미정이면 기간경과 손금, 사전-2026-법규법인-0062)에 따름(추가확인 필요).

## 주제별 결론 강도
* A (전액 손금 vs 자산계상): **가능성 있음**. 국세청 해석은 2018~2026 일관되게 "퇴직기한 미정·만기환급금 없음이면 기간경과 손금"이나, 조세심판원 국심2006서3194가 결산일 해약환급금 자산계상으로 판단한 상반례가 있고, 임원 정년 규정이 있으면 법규법인2013-397에 따라 자산계상 요구 가능.
* B (해지 시 익금): **확정**. 해약일 사업연도 익금(자산계상분 있으면 차액). 감액완납도 변경일 익금.
* C (명의변경 평가·소득구분·부당행위): **추가확인 필요**. 퇴직 시 이전은 퇴직소득(한도초과 근로소득)으로 정리됐으나, 평가액(해약환급금 vs 납입보험료)은 국세청이 사실판단으로 미루었고 판례도 엇갈림.
* D (대표 근로소득 여부): **확정**. 계약자·수익자 법인이면 근로소득 아님. 수익자 일부가 임원·유족이면 해당 부분 과세.
* E (과다가입 업무무관 부인): **추가확인 필요**. 규모 과다를 이유로 한 부인 심판례·판례는 검색되지 않음. 업무무관 전액 부인을 배척한 2007년 심판례만 확인.
* F (외화보험 환산): **추가확인 필요**. 법인 보유 외화보험 직접 해석 없음.
* G (과세이연·전환): **가능성 있음**. 과세관청은 구조를 부인하지 않고 해지·변경 시점 익금 + 상여 한도로 통제. 종신 전환 처리 해석은 없음.
