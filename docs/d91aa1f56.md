# 수당 체계와 2027 분급제

> **한눈에** 지금 수당 구조와 2027년부터 바뀌는 분급제를 비교한 안내입니다. 핵심은 **2027년부터는 "얼마나 많이 넣었나"보다 "얼마나 오래 유지되나"가 소득을 결정한다**는 점입니다.

⚠ 아래 규칙은 외부 계산기 표기를 옮긴 것으로, 감독규정 원문과 본사 지급 규정 확인이 끝나지 않았습니다(확인 필요). 본인 지급률·환수 기준은 지점장에게 확인하세요.

## 한 장 요약

| 구분 | 지금 (~2026.12 체결분) | 4년 분급 (2027~2028) | 7년 분급 (2029~) |
|---|---|---|---|
| 규제 | 1200% 룰 | 1200% 룰 + 4년 분급 | 1200% 룰 + 7년 분급 |
| 1년차 재원 | **1,200%** | 선지급 **970%** + 유지관리 **225%** | 선지급 **970%** + 유지관리 **120%** |
| 나머지 | 없음 | **36개월** 분할 | **72개월** 분할 |
| 현금 흐름 | 익월 집중 | 4년 분산 | 7년 분산 |
| 끝까지 유지 시 총량 | 기준 | 약 **+11%** | 약 **+28%** |
| 계약이 깨지면 | 받은 수당 **환수** | 남은 분급 **증발**(환수 여부 확인 필요) | 남은 분급 **증발**(환수 여부 확인 필요) |

## 지금 구조 (2026년 12월 체결분까지)
1. 흐름: 보험사 → GA → 관리자 OR 차감 → 본인 지급률 적용 → 본인 수령
2. **1200% 룰(GA 2026.07~):** 첫해 수수료 총액은 월보험료의 **1,200%** 이내, OR·시책 포함. 월보험료 10만원이면 첫해 **120만원**까지.
3. 지급 시점: 계약 다음 달에 첫해분이 몰려서 지급
4. 리스크: 일찍 해지되면 받은 수수료 **환수**. 환수 기간·비율 기준은 자료에 없음(확인 필요)
- ⚠ "13차월 미만 유지 시 환수"는 캠페인 시상 조건이며 환수 규정 전체가 아닙니다.

## 2027 분급제 공식

| 단계 | 1년차 수령 공식 | 잔여 |
|---|---|---|
| 시행 전 | (1,200% − OR) × 본인 테이블 | 없음 |
| 4년 분급 | (970% + 유지관리 225% − OR) × 본인 테이블 | 36개월 분할 |
| 7년 분급 | (970% + 유지관리 120% − OR) × 본인 테이블 | 72개월 분할 |

- 1차년도 선지급 한도: **1,150% → 970%(약 16% 축소)**
- 계산기 기본값 OR **30%**, 본인 지급률 **70%**는 실제 값이 아닙니다.
- ⚠ 중도 해지 시 잔여 수당은 사라집니다.
- "− OR"이 %p 차감인지 비율 차감인지 불분명(확인 필요). 근거 개정안은 원문 대조 전입니다(확인 필요).

## 숫자로 보기 (월보험료 10만원, OR·지급률 적용 전)

| 구분 | 1년차 재원 비율 | 금액 | 그 뒤 |
|---|---|---|---|
| 시행 전 | 1,200% | **120만원** | 없음 |
| 4년 분급 | 970% + 225% = 1,195% | **119.5만원** | 36개월 분할 |
| 7년 분급 | 970% + 120% = 1,090% | **109만원** | 72개월 분할 |

- 실제 수령액은 여기서 OR과 본인 지급률을 적용하며, 상품 총 지급률이 1,200%보다 낮으면 더 줄어듭니다.
- 분급 잔여 총액은 자료에 없어 계산하지 않았습니다(확인 필요).

**내 수당 계산 연습지:** 상품 총 지급률 / 관리자 OR 합계(차감 방식 포함) / 본인 지급률 / 환수 기간·비율 / 분급 적용 기준(청약일 또는 성립일, 확인 필요)

## 환수와 잔여 수당 증발은 다릅니다

| 구분 | 언제 | 무슨 일 |
|---|---|---|
| 환수 | 지금 구조에서 일찍 해지·실효 | 받은 수수료를 돌려냄 |
| 잔여 수당 증발 | 분급제에서 해지 | 안 받은 분급분을 못 받음 |
| 둘 다? | 분급제 1년차 선지급분 환수 여부 | 자료에 없음(확인 필요) |

- 경정기는 저해약환급금형이라 **3년 이전 해지 시 환급금 0%**, 3~5년 **50%** 구간입니다.
- 일찍 깨지면 고객도 손해, 지점원도 손해입니다. **무리한 금액·상품은 양쪽 모두 손해**입니다.

## 유지율을 지키는 습관

| 습관 | 내용 |
|---|---|
| 완납 전제로 판매 | 해지 전제 판매는 불완전판매. 환급률로 먼저 설득하지 않기 |
| 단점 먼저 고지 | 3년 미만 해지 시 0%, 7년 유지 전제 상품임을 먼저 알림 |
| 재정심사 범위 안에서 | 낼 수 있는 금액으로 설계, 선심사 먼저 |
| 청약 직후 케어 | 첫 납입까지 대표가 불안해하는 기간에 연락 |
| 증권 전달 = 사후관리 | 한 달 뒤 보장분석, 3개월 차 관리, 2년 후 재방문 |
| 컨설팅 대가로 묶지 않기 | 대가로 묶으면 1~2년 안에 해지되기 쉬움 |
| 장기 일정 약속 | 결산 1개월 전 브리핑 등 최소 2년 일정 명시 |

## 지점 운영에서 알아둘 점
- **2026년 12월까지 체결분은 기존 구조**입니다. ⚠ 연내 체결 동기는 내부 사정이지 고객용 화법이 아닙니다.
- 지점장 OR도 분급 대상이라 지점 현금흐름 계획이 필요합니다.
- 유지율 높은 상품의 의미가 커지지만, 상품 선택은 **고객 니즈가 먼저**입니다.
