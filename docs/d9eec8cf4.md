# 차명주식(명의신탁) 환원

## 한 줄 정의

설립 당시 발기인 요건 등으로 타인 명의로 둔 주식을 실제 소유자에게 돌리는 작업. 해지·양수도·증여·법인 취득·제3자 경유 중 세부담과 리스크를 비교해 선택.

## 대상 업체 신호

**신호**

舊 상법 발기인 7인(1995년 이전)·3인(2001년 이전) 시절 설립 법인, 건설업 자본금 요건, 외투법, 주주명부에 친인척·직원. 리스크: 수탁자 배신·임의처분·수탁자 상속 개시·입증 곤란·명의신탁 증여의제(상증법 §45의2, 실제소유자가 납부의무).

## 해결 구조

**솔루션 비교(기업의별 강의)**

명의신탁 해지(증여세 가능, 부과제척 15년, 소송으로 주주권 입증 필요, 입증 시 세부담 적음) / 시가 양수도(개인재원·양도세·현금흐름 입증) / 증여(현금 불필요, 명의신탁 의심, 10년 합산) / 법인 취득(법인재원, 추가 증여의제) / 제3자 경유(제2·3의 명의신탁, 새로운 증여의제). "명의신탁 해지時 Tax << 현재 시점에서의 주식이동時 Tax".

**프로세스**

주식이동 파악(설립·증자·감자·양도) → 각 시점 주가 → 주주 협조성 → 과세금액(증여세+명의개서 불이행+소득세 등) → 특수관계 → 증빙(신탁 당시 금융기록, 판결문, 우회배당 기록, 신·수탁자 자력·나이·연관성, 차명주주 사업·근무이력, 실질주주의 경영행사 증빙) → 소명 불가 사유 → 시각화. 해지 시 세금: 신탁 당시 증여세, 신고·납부불성실, 주식등변동상황명세서 가산세, 누락 배당소득세, 원천징수불이행, 증권거래세, 간주취득세(지방청 별도). 판례: 명의개서는 "실질주주가 주주명부상의 명의를 회복한 것에 불과"해 간주취득세 과세대상 아님(대법원 98두7619).
**환원 불가 시 대비**: 양도제한·종류주식 전환(특별결의), 녹취, 신탁·해지약정서(인감·확정일자), 주권 발행 후 보관, 민사신탁.

## 연계 보험상품과 연결 논리

**영업 연계**

상속감자 실행 전 차명주주 정리 필요성, 1차 확인자료에 "차명·명의신탁 이슈 여부"(상가 1차 v4). 교육과정·결산특강의 박영태 변호사 차명주식 환원 강의는 판독 불가(아래 목록).
