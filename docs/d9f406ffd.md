# 단기납종신 환급률 비교

> **한눈에** 40세 남성, 저해약환급형 기준으로 생보사 단기납종신의 납입기간별 환급률을 비교했습니다. 개인 대표나 임원에게 단기납종신을 고를 때 씁니다. "납입완료"는 해당 납입기간이 끝난 시점의 환급률입니다.
> 내부 참고용. 고객에게는 가입설계서·상품설명서 기준으로 안내.

## 3줄 정리
1. **메트 달러 백만종(백만인을위한달러종신Plus)**이 모든 조건에서 10년 환급률 1위(**117.8~124.9%**).
2. 원화 상품은 10년 기준 **117~121%**대에 몰려 있어 차이가 작습니다. 20년 이후 장기 환급은 처브·ABL·하나·라이나가 높은 편.
3. 비교 시점(10년인지 20년 이후인지)을 먼저 정해야 1위가 정해집니다.
