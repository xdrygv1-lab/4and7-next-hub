# 메트라이프 무배당 변액유니버셜 모두의상속종신보험 요약

> 용도: 법인 대표·자산가 상담 전 확인용 / 변액 경영인정기(MAVERICK) 이해 기초자료
> 근거: 상품요약서(일반가입형·간편가입형 공통), 파일 버전 20260701_v2
> 원칙: 원문 수치 그대로. 원문에 없는 항목은 "요약서에 없음"으로 표기.

## 1. 한 줄 요약

사망 시 기본보험금액, 계약자적립액의 105%, 기납입보험료 중 가장 큰 금액을 지급하는 변액유니버셜 종신보험이며, 펀드 실적이 나빠도 계약유지보증기간 동안 기본보험금액(최저사망보험금)을 보증하지만 해약환급금 최저보증은 없습니다.

## 3. 보장 구조

### 주계약 사망보험금

| 구분 | 내용 |
|---|---|
| 지급사유 | 보험기간 중 피보험자 사망 |
| 기본 지급액 | 기본보험금액 (보험가입금액의 100%) |
| 실제 지급액 | 아래 셋 중 가장 큰 금액: (1) 기본보험금액 (2) 계약자적립액 × 105% (3) 기납입보험료 |
| 간편가입형 예외 | 계약일부터 2년 미만 재해 이외 원인 사망 시 보험가입금액의 50% |

### 기본보험금액의 변동

| 사유 | 기본보험금액 변화 |
|---|---|
| 중도인출 | 인출 전 기본보험금액 − 중도인출금액 |
| 추가납입 | 추가납입 전 기본보험금액 + 추가납입보험료 |

※ 요약서에는 "변동보험금"이라는 별도 용어는 없음. 실적 연동 부분은 "계약자적립액 × 105%" 비교 방식으로 반영됨.

### 최저사망보험금 보증 (계약유지보증)

| 항목 | 내용 |
|---|---|
| 최저사망보험금 | 계약유지보증기간 동안 운용실적과 관계없이 보장하는 기본보험금액 |
| 보증기간 종류 | 종신보증, 80세보증, 65세보증 (최초 가입 시 종신) |
| 가입나이 60세 초과 | 최단 보증기간은 80세 보증 |
| 테스트 시점 | 계약일부터 매 6개월이 되는 달의 마지막 날 |
| 테스트 방식 | 순납입보험료 ≥ 보증기간별 기준보험료 누계 → '충분' / 미만 → '부족' |
| 순납입보험료 | 기본보험료 + 추가납입보험료 − 중도인출금액 − 월대체공제된 특약보험료 − 상환하지 않은 보험계약대출 원리금 |
| 실제 납입 보험료 | 종신보증 기준보험료 (80세·65세 기준보험료는 테스트용) |
| 보증 시작 | 36개월 경과 후 해약환급금으로 월대체공제액 충당 불가 + 납입최고기간 내 미납이어도 보증이 유효하면 해지 없이 최저사망보험금 보장 |
| 납입기간 중 보증 시작 시 | 매월 말 테스트, 결과에 따라 보증기간 단축 가능 |
| 보증기간 연장용 납입 | 연간 납입한도 적용 제외 |
| 적용이율 | 최저사망 보장부분 연복리 3.00% (적립액·해약환급금 보증이율 아님) |

### 기타

- 펀드장기유지보너스: 계약일부터 5년 경과 후 매월 계약해당일에 기본보험료에 의한 계약자적립액에 가산. 지급률은 요약서에 없음. 해약환급금으로 월대체공제액 충당 불가 시에는 가산하지 않음.

## 4. 변액 구조

### 선택 가능 펀드

| 펀드 | 유형 | 조건 |
|---|---|---|
| 장기채권형 | 채권형 | 투입비율 30% 이상 필수 |
| 인덱스주식형 | 주식형 | |

- 펀드 수: 2개
- 1개 이상 선택, 복수 선택 시 5% 단위 투입비율 지정
- 추가납입보험료는 기본보험료 투입비율을 따름
- 해약환급금 예시 기준 배분: 장기채권형 70% + 주식형 30%

### 펀드 운용 관련 조건

| 항목 | 내용 |
|---|---|
| 펀드 변경 횟수/조건 | 요약서에 없음 |
| 자동재배분 | 요약서에 없음 |
| 계약자적립액 | 펀드 기준가격에 따라 매일 변동 |

### 비용 구조

| 비용 | 요약서 내용 | 수치 |
|---|---|---|
| 특별계정 운용보수 | 운영보수 + 투자일임보수 + 수탁보수 + 사무관리보수 합계. 매일 차감되어 기준가격에 반영 | 요약서에 없음 |
| 증권거래비용·기타비용 | 매일 차감되어 기준가격에 반영 | 요약서에 없음 |
| 계약유지보증비용 (최저보증비용) | 최저사망보험금 지급 보증 비용. 월대체공제액에 포함 | 요약서에 없음 |
| 계약체결비용·계약관리비용 | 보험료 중 일정비율 책정 | 요약서에 없음 |
| 위험보험료 | 주계약 보험사고 대비 | 요약서에 없음 (위험률 예시만 있음) |
| 추가납입 계약관리비용 | 추가납입보험료에서 차감 | 요약서에 없음 |

### 월대체공제와 특별계정 투입 구조 (36개월 경계)

| 구분 | 36개월(36회 납입) 이내 | 37회 이후 |
|---|---|---|
| 특별계정 투입보험료 | 납입보험료 − 계약체결비용·계약관리비용 − 위험보험료 − 특약보험료 | 납입보험료 − 계약관리비용 중 기타비용 |
| 월대체공제액 | 계약자적립액에서 계약유지보증비용만 공제 | 해약환급금에서 위험보험료, 계약유지보증비용, 계약체결비용, 계약관리비용(기타비용 제외), 특약보험료 공제 |

※ 납입기간 이후 갱신형특약 보험료는 월대체공제 및 특별계정 투입 대상에서 제외.

## 6. 유니버셜 기능

| 기능 | 조건 |
|---|---|
| 추가납입 | 기본보험료 총액(기본보험료 × 12 × 납입기간) 완납 이후 수시 납입. 최소 10만원. 중도인출이 있으면 완납 전이라도 (인출 누계 − 추가납입 누계) 범위 내 가능 |
| 납입 총한도 | 기본보험료 + 추가납입 합계 기본보험료 총액의 200% 이내 (인출 누계만큼 한도 증액, 특약보험료 제외) |
| 연간 납입한도 | 36회 이내: 기본보험료 × 12 × 100% / 37회 이후: 기본보험료 × 12 × 200% |
| 중도인출 | 36개월(36회 납입) 경과 후, 해약환급금(보험계약대출금 차감)의 50% 이내, 보험년도 기준 연 4회, 월계약해당일 기준 1개월 1회 |
| 중도인출 제한 | 인출 후 해약환급금 ≥ min(연간기본보험료(기본보험료 12배), 500만원), 총 인출금액 ≤ 실제 납입보험료 총액의 50% |
| 중도인출 효과 | 기본보험금액이 인출액만큼 감소, 순납입보험료 감소로 보증 테스트에 불리 |
| 보험료 납입유예(일시중지) | 해약환급금에서 월대체공제액 차감 가능 시 유예 가능. 과도한 사용 시 조기 해지 및 계약유지보증기간 단축 |
| 감액 | 가능. 감액 시 기납입보험료·순납입보험료가 감액 후 적립액 비율로 재계산. 세부 요건은 요약서에 없음 |
| 보험계약대출 | 가능. 미상환 원리금은 순납입보험료에서 차감 |

## 9. 영업 포인트 (상속재원 관점)

1. 최대 50억원(일반가입형)까지 주계약 가입이 가능하고 보험기간이 종신이므로, 사망 시점이 언제든 기본보험금액 이상이 지급되는 상속재원 설계에 맞는 구조입니다.
2. 계약유지보증 테스트를 '충분'으로 유지하면 펀드 실적과 무관하게 기본보험금액이 보증되므로, 상담 시 "기준보험료 이상 꾸준히 납입, 인출 최소화"를 함께 안내해야 합니다.
3. 실적이 좋으면 계약자적립액 105%가 기본보험금액을 넘어 사망보험금이 늘고, 추가납입분은 기본보험금액에 그대로 더해지므로 여유자금을 상속재원으로 이전하는 통로로 설명할 수 있습니다.
4. 법인이 계약자·납입자이면 예금자보호 대상이 아니라는 점은 법인 대표 상담에서 반드시 고지해야 합니다.
5. 상속세 납부재원, 계약자·수익자 설정에 따른 과세 여부는 세법 확인필요.

## 10. 변액 경영인정기 상담 전에 알아둘 변액 공통 개념

1. 특별계정과 계약자적립액: 보험료 일부가 일반계정과 분리된 특별계정 펀드에 투입되고, 적립액과 해약환급금은 기준가격에 따라 매일 변동합니다.
2. 월대체공제: 위험보험료, 계약유지보증비용, 사업비가 매월 적립액·해약환급금에서 빠지므로 납입을 멈추면 적립액이 줄고 해지될 수 있습니다.
3. 최저보증 범위: 이 상품은 사망보험금만 최저보증하고 해약환급금은 보증하지 않습니다. 경영인정기에서 환급금 보증이 있는지 반드시 비교 확인해야 합니다.
4. 비용 위치: 운용보수·거래비용은 기준가격에서 매일 차감되고, 보증비용·사업비는 월대체공제로 빠집니다. 요약서에는 요율이 없어 사업방법서·상품설명서로 확인해야 합니다.
5. 법인계약과 예금자보호: 계약자 및 납입자가 법인이면 예금자보호가 적용되지 않으므로 법인 계약 위주인 경영인정기 상담 시 공통 고지사항입니다.
