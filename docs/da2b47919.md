## 쟁점 1. 보험료: 전액 손금인가, 자산 계상인가

【결론】 퇴직기한(임원 정년)이 정해지지 않았고 만기환급금이 없는 정기보험이면 **납입보험료를 보험기간 경과에 따라 손금**으로 보는 것이 국세청의 현재 일관된 입장. TheClassic은 90세 만기 환급금 0이므로 원칙적으로 월납 보험료 전액 손금 처리 가능. 단 **정관에 임원 정년이 있으면 정년 시점 해약환급금 상당액은 자산 계상** 대상.

【근거】
- [확인된 사실] 법인세법 제19조②, 시행령 제19조 제24호(그 밖의 손비). 보험료를 직접 규정한 조문은 없음
- [확인된 사실] 서면-2020-법인-3181(2020.08.14): "경영인정기보험", 퇴직기한 미정·만기환급금 없음 → 기간경과분 손금. 서면-2018-법인-1779 같은 취지
- [확인된 사실] 기재부 법인세제과-306(2015.4.20): 퇴직시점 예상 불가 시 만기환급금 상당액만 자산
- [확인된 사실] 법규법인2013-397(2013.10.24): 임원 정년 규정이 있으면 정년퇴직 시점 해약환급금 상당액은 자산
- [확인된 사실] 사전-2026-법규법인-0062(2026.05.11): 5년납 종신보험도 같은 결론, 표현은 "보험기간 경과에 따라" 손금

【리스크】
- [잠정 데이터] 조세심판원 국심2006서3194(2007.04.04)는 "각 사업연도말 해약환급금 상당액"을 자산으로 봄. 조사 시 과세관청이 이 논리를 쓸 여지
- [잠정 데이터] "납입 즉시"가 아니라 "기간 경과" 손금. 전기납 월납은 문제없으나 **단기납·고액 선납** 구조는 보험기간 안분 논점
- [자문 의견] 과다가입을 업무무관으로 부인한 사례는 찾지 못했지만(국심2006서3194는 업무무관 부인을 배척), 소득·자본 대비 과도한 보험료는 조사 쟁점이 될 수 있음. 재정심사 범위 내 가입이 방어선

【체크】 정관 임원 정년 규정 유무 / 이사회 의사록(가입 목적: 경영인 유고 대비) / 보험료 규모의 합리성

## 쟁점 2. 해지·감액완납·전환 시 해약환급금 익금

【결론】 해약환급금은 **해지일(계약변경일)이 속하는 사업연도 익금**. 보험료를 전액 손금 처리했다면 환급금 전액이 익금. 감액완납도 계약변경일에 해약환급금 상당액을 익금 인식.

【근거】
- [확인된 사실] 법인세법 제40조①(권리의무확정주의)
- [확인된 사실] 서면-2018-법인-1779, 서면-2020-법인-3181: 해약일 사업연도 익금
- [확인된 사실] 서면-2019-법인-3522(2020.08.28): 감액완납 시 변경일에 해약환급금 상당액 익금, 이후 잔여 보험기간에 걸쳐 손금
- [확인된 사실] 사업방법서: 종신전환·연금전환 모두 "주계약 해약환급금 기준", 종신전환은 "전부 해지" 요건

【리스크】
- [잠정 데이터] 종신전환·연금전환 시 처리를 직접 다룬 해석 없음. 사업방법서 구조(해지 후 해약환급금 일시납)상 **전환 시점 익금 + 새 계약 보험료 처리(종신은 자산 계상 가능성)**로 보는 것이 보수적
- [자문 의견] 전환 = 과세 발생 시점. "전환하면 세금 없이 넘어간다"는 설명은 금지

## 쟁점 3. 대표 소득 과세 (가입 중 / 명의변경)

【결론】 가입 중에는 계약자·수익자가 법인이면 **대표 근로소득 아님**. 대표에게 명의변경하면 **현실적 퇴직이면 퇴직소득(임원 한도 초과분 근로소득), 퇴직 없이 넘기면 근로소득**. **평가액은 확정된 기준이 없음.**

【근거】
- [확인된 사실] 소득세법 시행령 제38조①12호: 종업원이 계약자이거나 종업원·가족이 수익자인 보험료만 근로소득
- [확인된 사실] 서면2팀-1631 등: 계약자·수익자 법인이면 근로소득 아님
- [확인된 사실] 서면-2019-법인-0560(2020.07.08): 사망보험금 수익자를 유족으로 지정하면 보험금 지급 시 손금불산입, 기타소득 처분
- [확인된 사실] 퇴직소득: 기재부 소득세제과-109(2011.3.29), 서면-2016-법령해석소득-3158, 서면-2022-원천-3587(2023.02.24)
- [확인된 사실] 근로소득: 소득세과-3449(2008.09.29, 대표직만 변경, 납입보험료 상당액)
- [확인된 사실] 소득세법 제22조③: 임원 퇴직소득 한도 2012~2019 근무분 3배, 2020년 이후 2배
- [확인된 사실] 서면-2023-법규법인-1077(2023.11.28): 명의변경 후 대표가 해지해 환급금 수령해도 법인은 별도 처리 없음 → 법인 쪽 과세는 명의변경 시점에 정리

【평가액 상반】
- [잠정 데이터] 납입보험료 기준: 소득세과-3449, 서울고법 2015누40400(2015.09.02)
- [잠정 데이터] 해지환급금 기준: 서울행법 2014구합68140(2015.04.02), 상증세 최신 사전-2025-법규재산-0746(2025.10.01, 기재부 재산세제과-929 인용)
- [잠정 데이터] 법인세과-640(2009.05.28): 정상거래가격 / 서면-2022-원천-0118: 사실판단
- [확인된 사실] 시가보다 낮게 넘기면 법인세법 시행령 제88조①3호 부당행위계산(차액 3억 또는 시가 5% 이상)
- [확인된 사실] 상증법 제34조①: 보험료 부담자와 수령인이 다르면 보험사고 시 증여 쟁점

【자문 의견】 저해약형은 초기 해약환급금이 납입보험료보다 훨씬 작아 평가액 차이가 큼. "해약환급금으로 낮게 평가해 넘긴다" 설계는 부당행위·증여 리스크가 커서 **고객에게 확정적으로 제안하지 말 것**. 실행 시 사전답변 신청 검토

## 쟁점 4. 대표 퇴직 시점과 해지 환입 매칭

【결론】 [자문 의견] 구조 자체는 국세청도 부인하지 않음(서면-2020-법인-0953: "보험료 손금 + 해지환급금으로 상여" 광고가 사실관계에 나왔으나 해지 시 익금 과세와 상여 한도 통제를 전제로 회신). **해지 익금이 생기는 연도에 임원 퇴직금(손금)을 맞추면 법인세 부담이 상쇄**되는 효과는 가능. 다만 퇴직금이 손금 한도 안이어야 함.

【근거】
- [확인된 사실] 법인세법 시행령 제44조④: 임원 퇴직금 손금 한도 = 정관 규정액(퇴직급여지급규정 포함), 없으면 1년 총급여 × 1/10 × 근속연수. 초과분 손금불산입
- [확인된 사실] 시행령 제44조②: 현실적 퇴직 요건(중간정산 등)
- [확인된 사실] 시행령 제43조②③: 급여지급기준 초과 임원 상여, 지배주주 임원 과다 지급 손금불산입
- [확인된 사실] 서면-2020-법인-0953: 해지환급금으로 상여 지급 시 기준 초과분 손금불산입
- [확인된 사실] 사업방법서 조기 계약전환 사유에 "대표이사 직위 변경" 포함(36회 이상 납입)

【설계 체크리스트】
1. 정관·임원퇴직급여지급규정 정비(배수, 지급 근거). 개정 시점과 소급 적용 리스크 확인
2. 퇴직 예정 연도에 해지 또는 전환 배치 → 익금과 퇴직금 손금 같은 사업연도
3. 개인 측: 임원 퇴직소득 한도(2020년 이후 2배) 초과분은 근로소득 → 대표 개인 세부담 별도 계산
4. 10년 시점 환급률 정점(달러 95%대) 이후 해지가 법인 현금흐름에 유리. 정년 규정이 있으면 쟁점 1 자산 계상과 충돌 여부 확인

## 쟁점 5. 달러보험 환산

【결론】 [잠정 데이터] 일반법인 보유 외화보험을 직접 다룬 해석은 없음. 법인이 **화폐성 외화자산 평가방법(기말환율)을 신고**했다면 환산손익을 익금·손금 산입하는 일반 규정 적용 여지. 다만 보험계약이 화폐성 외화자산인지, 그리고 전액 손금 처리로 장부상 자산이 없으면 환산 대상 자체가 없는지 정리 필요.

【근거】
- [확인된 사실] 법인세법 제42조, 시행령 제73조 제3호·제76조②④⑤: 기업회계기준상 화폐성 외화자산, 신고 방법에 따라 환산
- [확인된 사실] 서면-2017-법인-3219(2018.02.27): 기말환율 신고 시 화폐성 외화자산 환산차손익 산입
- [확인된 사실] 서면-2020-법령해석소득-1222(2021.03.19, 개인 저축성): 외화 차익을 지급일 환율로 환산

【자문 의견】 실무상 보험료는 납입일 환율로 손금, 해지 시 해약환급금은 수령일 환율 원화로 익금 처리가 가장 단순하고 보수적. 원화고정납 옵션은 환율 변동을 납입 측에서만 줄일 뿐 환급 측 환율 리스크는 남음을 고객에게 고지

## 종합 결론 강도
| 쟁점 | 강도 |
|---|---|
| 1. 보험료 손금 | 가능성 높음 (정년 규정·심판례 리스크) |
| 2. 해지 익금 시점 | 확정 / 전환 시 처리는 추가확인 필요 |
| 3. 가입 중 근로소득 아님 | 확정 / 명의변경 평가액은 추가확인 필요 |
| 4. 퇴직 매칭 | 가능성 있음 (한도·규정 정비 전제) |
| 5. 달러 환산 | 추가확인 필요 |

## 영업 멘트에서 지켜야 할 선
- "100% 손금"은 **"퇴직 시점이 정해지지 않은 정기보험은 국세청 해석상 보험료를 기간경과에 따라 손금 처리"**로 표현
- "세금 이연"은 맞지만 **해지·전환 시 전액 익금**임을 반드시 함께 설명
- 명의변경 저가 평가 설계는 확정 제안 금지
- 정관 임원 정년·퇴직금 규정 검토를 상품 제안 전 단계에 포함 (세무사 차별점)
