## 2. 나에게 맞는 트랙 고르기

두 트랙은 **내용의 기준은 같고 보는 방식만 다릅니다.** 어느 쪽을 골라도 01~04 본문을 함께 참고하시면 됩니다.

| 질문 | 예 → | 아니오 → |
|---|---|---|
| 종이로 출력해서 형광펜 치며 보는 게 편하다 | 노세대 트랙 | 신세대 트랙 |
| 설명보다 체크리스트와 예시가 먼저 보고 싶다 | 신세대 트랙 | 노세대 트랙 |
| AP 스크립트 생성기·시뮬레이터 같은 도구를 써 볼 생각이 있다 | 신세대 트랙 | 노세대 트랙 |

### 노세대 트랙 (간결·인쇄형)
1. **노세대트랙_핵심요약.md** 를 A4로 출력합니다 (2~3쪽).
2. 모르는 단어가 나오면 **01_보험용어_사전.md** 에서 찾습니다. 용어 사전도 묶음별로 출력해 두시면 편합니다.
3. 첫 청약 전에는 **03_청약서_작성가이드.md** 의 "청약 전 체크리스트" 1쪽만 출력해 들고 가십시오.
4. 수당은 **02_수당체계_2027분급제.md** 의 "한 장 요약" 표만 보셔도 충분합니다. 본인 지급률은 지점장에게 직접 확인합니다.

### 신세대 트랙 (빠른 시작·디지털)
1. **신세대트랙_빠른시작.md** 의 "첫 30일 할 일" 체크리스트부터 시작합니다.
2. 용어는 **01_보험용어_사전.md** 에서 Ctrl+F로 검색합니다.
3. AP 전에는 **AP 스크립트 생성기**, 경정기 비교 때는 **경정기 시뮬레이터**를 씁니다 (링크는 04번 문서).
4. 숫자를 고객에게 보여줄 때는 반드시 **실제 가입설계서**로 확인합니다. 도구 수치는 내부 검토용입니다.

### 모든 문서에 공통으로 지키는 원칙
1. **수익을 약속하는 말은 쓰지 않습니다.** "확정 수익", "무조건 남는다", "원금 보장되니 저축처럼" 같은 표현은 금지입니다. 보장성 보험은 저축 상품이 아닙니다.
2. 세무 처리(비용처리·손금·익금 등)는 세무사 검토 사항입니다.
3. **고객 화면의 숫자는 실제 가입설계서가 기준입니다.** 이 가이드북의 환급률·보험료는 2026년 9~10월 비교자료 기준 예시입니다.
4. **개인정보는 담지 않았습니다.** 특정 고객, 특정 지점원의 실적·수당은 넣지 않았습니다.
