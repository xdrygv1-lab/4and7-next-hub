# 지점원 기본 가이드북

> **한눈에** 보험용어, 청약서 작성을 한 묶음으로 정리한 안내서의 목차입니다. 본업을 하며 보험을 함께 다루는 지점원, 특히 보험이 처음인 분을 위한 출발점입니다.

## 무엇이 들어 있나요

| 번호 | 내용 |
|---|---|
| 01 | 보험용어 사전: 꼭 필요한 용어를 묶음별로 쉬운 설명과 예시로 |
| 03 | 청약서 작성 가이드: 체크리스트, 작성 순서, 자주 하는 실수, 심사 대비 |
| 04 | 영업 흐름 한 장 요약: PS → TA → AP → PC → 계약 → 소개·사후관리 |
| 자료 | 상품 자료 찾고 받기: 안내장··청약 서식 내려받는 법 (이 문서 아래) |
| 트랙 | 노세대 트랙, 신세대 트랙(체크리스트·첫 30일·도구) |

## 나에게 맞는 트랙 고르기

두 트랙은 **내용 기준은 같고 보는 방식만 다릅니다.**

| 이런 분이라면 | 추천 트랙 |
|---|---|
| 출력해서 형광펜 치며 보는 게 편하다 | 노세대 트랙 |
| 체크리스트와 예시를 먼저 보고 싶다 | 신세대 트랙 |
| AP 스크립트 생성기·시뮬레이터를 써 볼 생각이 있다 | 신세대 트랙 |

**노세대 트랙**
1. 핵심요약을 A4로 출력합니다(2~3쪽).
2. 모르는 단어는 용어 사전에서 찾습니다.
3. 첫 청약 전에는 청약 가이드의 "청약 전 체크리스트" 1쪽만 들고 갑니다.

**신세대 트랙**
1. "첫 30일 할 일" 체크리스트부터 시작합니다.
2. 용어는 사전에서 검색합니다.
3. AP 전에는 **AP 스크립트 생성기**, 경정기 비교에는 **경정기 시뮬레이터**를 씁니다.
4. 고객에게 보여줄 숫자는 반드시 **실제 가입설계서**로 확인합니다.

## 상품 자료 찾고 받기

안내장··약관·청약 서식은 왼쪽 메뉴 **상품 자료 받기** 한 곳에 모여 있습니다.

1. **상품 자료 받기**를 누릅니다. 처음 한 번은 팀 비밀번호를 넣습니다.
2. 위쪽에서 보험사(메트라이프·한화생명·KB라이프·신한라이프·삼성생명)를 고릅니다. 검색창에 상품 이름 일부만 쳐도 됩니다.
3. 상품을 누르면 그 상품 자료가 펼쳐집니다. 파란 **내려받기**를 누릅니다.

| 이럴 때 | 여기로 |
|---|---|
| 상품 안내장·가 필요하다 | 보험사 → 상품 → 내려받기 |
| 청약 서식·매뉴얼이 필요하다 | 보험사를 고른 뒤 맨 아래 «서식·매뉴얼·공통 자료» |
| 상품 내용부터 보고 싶다 | 상품 이름 옆 «상품 요약 →» |
| 상품 자료실을 보다가 파일이 필요하다 | 상품 카드의 «자료 받기 →» |
| 기간이 지난 자료는 빼고 보고 싶다 | «준법 기간 지난 자료 숨기기» 켜기 |

- 고객에게 보여 주는 것은 **고객용** 표시가 붙은 자료뿐입니다. **내부·교육용**은 공부용이라 고객에게 전달하지 않습니다.
- 여기 없는 자료가 있으면 «자료 올리기»로 올려 주세요. **고객 개인정보가 든 파일(제안서·청약서 등)은 올리지 않습니다.**

## 표기 규칙

| 표기 | 뜻 | 어떻게 쓰나 |
|---|---|---|
| **[확정]** | 약관·사업방법서 등 공식 기초서류에서 확인 | 최신판인지 확인 후 사용 |
| **[확인필요]** | 미확정이거나 자료끼리 다르거나 회사별로 다름 | 고객에게 말하기 전 지점장·원수사에 확인 |
| **[일반지식, 확인필요]** | 업계 일반 지식으로 적은 내용 | 참고만 |
| **(세무사 검토 필요)** | 세무 처리 관련 문구 | 단정 금지, 세무 판단을 거칠 것 |

## 모든 문서 공통 원칙
- **수익을 약속하는 말 금지:** "확정 수익", "무조건 남는다", "원금 보장" 등. 보장성 보험은 저축 상품이 아닙니다.
- 세무 처리(비용처리·손금·익금 등)는 세무사 검토 사항입니다.
- 고객 화면의 숫자는 **실제 가입설계서**가 기준입니다. 가이드북 수치는 2026년 9~10월 기준 예시입니다.
- 특정 고객·지점원의 개인정보와 실적은 담지 않았습니다.
