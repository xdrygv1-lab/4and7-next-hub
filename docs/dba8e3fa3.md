# 상품 비교 자료 활용법

> **한눈에** 보험 상품을 서로 비교한 자료는 "어떤 상품을 먼저 살펴볼지" 고를 때만 써요. 고객에게 보여주는 숫자는 반드시 보험사 가입설계서로 다시 확인해요.

## 비교 자료로 알 수 있는 것

| 자료 | 알 수 있는 것 | 이 사이트에서 쓰는 곳 |
|---|---|---|
| 경영인정기 비교 | 상품별 월보험료, 5·10·20·30년 환급률 | 경정기 비교 계산기 |
| 단기납 종신 비교 | 5·7·10년납 상품별 환급률, 보험료 | 상품 자료, 제안 준비 |
| 수수료 분급제 계산 | 2027년 분급제 전후 첫해 수령액 비교 | 지점원 교육 |
| 실손 세대 전환 계산 | 5세대로 바꿀 때의 보험료 절감과 보장 변화 | 대표·임직원 개인 보장 점검 |
| 보험사 소식지 | 이달 바뀐 상품, 출시 일정, 영업 이슈 | 매주 변경점 확인 |
| 보험사 연락처·서식 | 고객센터, 청구 팩스, 카드납 가능 여부 | 계약 후 관리 |

## 비교 자료에 없는 것

| 필요한 것 | 어떻게 채우나요 |
|---|---|
| 업체 재무제표, 기업 분석 | 고객이 준 재무제표, 공시 법인은 전자공시 자료 |
| 사업자번호로 업체 정보 불러오기 | 국세청 사업자 상태조회와 공시 자료 연결 (준비 중) |
| 재정심사 한도 (얼마까지 가입되는지) | 보험사 심사팀에 직접 확인하고, 승인 사례를 모아 둬요 |
| 보험료 비용 처리 판단 | 세무사 검토 사항 |

## 이렇게 써요

1. **후보 고르기**: 대표 나이와 예산으로 먼저 볼 상품 2~3개를 골라요.
2. **조건 확인**: 비교 기준(만기, 납입기간, 체증형 여부, 심사 유형)이 우리 고객과 같은지 봐요.
3. **설계서로 확정**: 고객에게 보여줄 숫자는 보험사 가입설계서로 다시 뽑아요.
4. **기록 남기기**: 실제 승인·거절 결과를 '함께 만들기'에 남기면 제안 금액이 더 정확해져요.

## 매주 확인하는 것 (월요일 15분)

- [ ] 비교 자료의 **기준월**이 바뀌었나요? 그대로면 "변동 없음"만 적어요.
- [ ] 비교 상품 **개수**가 늘거나 줄었나요?
- [ ] 10년 환급률 **1위 상품**이 바뀌었나요?
- [ ] 상품 **개정**(새 버전)이 있나요? 있으면 설계서를 다시 확인해요.
- [ ] 소식지에 **법인 상품**(경영인정기·종신) 관련 변경이 있나요?

## 꼭 지킬 것

- ⚠ 비교 자료의 숫자와 화면은 **고객에게 그대로 보여주지 않아요.** 내부 참고용이에요.
- ⚠ **달러 상품**은 환율에 따라 결과가 달라져요. 원화 상품과 같은 줄에 놓을 때는 꼭 구분해요.
- ⚠ 상품의 **가입 한도는 재정심사 한도가 아니에요.** 실제 가능 금액은 심사로 정해져요.
- ⚠ 외부 서비스에 **고객 이름, 생년월일, 회사명, 재무 숫자, 녹음 원문**을 넣지 않아요. 질문은 일반 문장으로만 해요.
- ⚠ 외부 세금 계산기는 세법 반영 시점이 불분명해요. 세무 판단에는 쓰지 않아요.
