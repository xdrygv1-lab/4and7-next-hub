# 부동산 현물출자 법인전환 + 자녀별 가족법인

> **한눈에** 임대용 상가를 법인에 현물출자해 부동산을 주식으로 바꾸고, 자녀별 가족법인이 부모 자금을 빌려 그 주식을 매년 사들이는 장기 승계 구조입니다. 증여나 양도보다 세 부담과 반복 비용을 줄이는 것을 목표로 합니다. 세무 처리는 세무사 검토 사항입니다.

## 이런 업체에 맞아요
- 부모·자녀 공동 보유 임대 상가(예: 감정 약 **80억**, 부모 90% / 자녀 10%)
- 목표 지분이 구체적이고 옮길 의사가 분명함
- 양도와 증여만 생각하고 있던 고객
- 상가 외 부모 금융자산이 있음(대여 재원). 없으면 진행이 어려움
- 손자녀가 있어 가족법인 주주로 배치 가능

## 대표가 느끼는 고민
- 지분을 세금 적게, 10년 합산 걱정 없이 옮기고 싶음
- 손자녀 세대에 다시 넘길 때의 비용
- 부모는 "단순하게 하고 싶다"

## 해결 방향
1. 증여·양도·현물출자 3안 비교로 출발
2. 법인 설립·현물출자, 양도세 이월과세 신청(취득세는 한 번 발생)
3. 자녀별 가족법인 설립(자녀·배우자·손자녀 주주)
4. 가족법인이 부모 자금을 빌려 현물출자 법인 주식을 매년 매매로 매입
5. 5년 사후관리 상한(처분 **50%** 미만) 지키며 단계적 이전, 이후 재개

| 방식 | 특징 |
|---|---|
| 단순 증여 | 총부담 약 **17.1억**, 10년 합산, 손자녀 재증여 비용 |
| 단순 양도 | 약 **10.3억** + 자녀 매입대금 조달 불가, 대금이 다시 상속재산 |
| 현물출자 | 초기 약 **4.5억** + 이월과세 약 **13.7억** 유예 |

⚠ 버전별로 감정가·수치가 바뀜(80억 → 68억 등). 최신 수치 확인 필요.

## 첫 미팅 질문
- "최종 목표가 지분 이전인지, 임대소득 이전인지, 상속세 절세인지요?"
- "장기 보유 후 다음 세대까지 넘길 생각이 있으세요?"
- "상가 외에 부모님 금융자산은 어느 정도 되세요?"
- "최근 10년 안에 증여하신 게 있으세요? 손주분들 나이는요?"

## 이렇게 말해 보세요
> "대표님, 핵심은 부동산을 직접 넘기지 말고 '주식'으로 바꾸는 겁니다."

> "양도세는 없어진 게 아니라 뒤로 미뤄진 겁니다. 이건 숨기지 않고 시작하겠습니다."

> "이 구조는 세금을 없애는 마법이 아니라, 시간과 구조로 관리하는 승계입니다."

## 자주 나오는 반론
| 반론 | 대응 |
|---|---|
| "5년 안에 무슨 일 생기면?" | 사후관리 위반이 아니면 구조는 유지, 주식이라 분할·납부 설계가 유연 |
| "감정가 낮추면 되지 않나" | 일부러 낮추는 건 위험. 두 곳 평가로 방어 가능한 근거 마련 |
| "초기 부담이 크다" | 법인이 승계한 개인사업장 현금으로 취득세 납부 |
| "건물 값이 떨어지면?" | 이전 단가도 내려가 오히려 이전이 쉬워짐 |
| "너무 복잡하다" | 고객이 할 일은 서명과 연 1회 점검, 관리는 전문가 몫 |

## 연결되는 상품
경영인정기보험(주식가치 관리, 퇴직금 재원, 상속세 재원)과 부모 잔여 지분 대비 종신보험. PC 단계에서만 언급.

## 꼭 확인할 것
- [ ] 사후관리 처분 상한 관리가 구조의 핵심
- [ ] 정식 감정평가 2곳, 대여계약·이자·대금 지급 증빙
- [ ] 자녀 가족법인의 소규모 임대법인 해당 여부와 적용 세율 (확인 필요)
- [ ] 유류분·가족 합의, 특수관계 임차인 임대료 시가, 미성년 주주 절차
- [ ] 등기부, 임대차계약서, 부모 금융자산, 기존 보험증권, 최근 10년 증여 내역
