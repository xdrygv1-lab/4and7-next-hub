# 상품 요약: TheClassic 달러경영인정기보험

> **한눈에** 달러 기준 순수보장성 **90세** 만기 정기보험으로, 10년 경과 후 매년 가입금액의 **10%**씩 사망보험금이 정액 체증합니다. 저해약환급금형이라 3년 이전 해지 시 환급금 **0%**입니다. 대표 유고 대비 보장을 달러로 마련하려는 법인에게 씁니다.
> 내부 참고용. 고객에게는 가입설계서·상품설명서 기준으로 안내.

## 이런 고객에게
- 대표 유고 대비 보장이 시간이 갈수록 커지길 원하는 법인 (10년 후 매년 10% 체증)
- 달러 자산 분산을 원하는 법인 (원화로 납입·수령도 가능)
- **최소 5년 이상** 유지할 수 있는 납입 여력이 있는 법인

## 설명할 때 꼭 말할 것
- ⚠ 3년 이전 해지 시 환급금 **0%**, 3~5년 **50%**. 예시상 일반 남 3년 시점 **36.7%**
- ⚠ 순수보장성이라 90세 만기 시 환급금 **0**. 환급률은 10년 전후가 최고
- ⚠ 원화 환산 금액은 환율에 따라 달라집니다
- ⚠ 간편형은 2년 미만 재해 외 사망 **50%**, 보험료·가격지수(남 **121.2%**)가 높음
- 원화 상품(이율 2.5%, 10년 환급률 90.6%)보다 이율과 10년 환급률이 높지만, 환율 설명이 필수

> "대표님, 10년이 지나면 보장이 매년 늘어나는 구조이고, 5년이 지나면 환급률이 80%대로 회복됩니다. 그래서 최소 5년 이상 유지를 전제로 말씀드립니다."

## 자주 헷갈리는 점
| 헷갈리는 점 | 정리 |
|---|---|
| 만기에 돈이 돌아온다? | 순수보장성. 만기 환급금 **0** |
| 플러스보험기간은 무조건? | 만기 계약자적립액이 0을 넘을 때만. 대출이 있으면 그만큼 차감 |
| 3년·5년 예시 비율 그대로? | 3년+1일, 5년+1일 시점 비율 적용값이라 실제는 더 적을 수 있음 |
| 감액완납·조기계약전환은? | 요약서에 없음. 약관에서 확인 (약관: 5년 후 감액완납, 36회 후 조기 전환) |
