# 상품 요약: TheClassic 원화 경영인정기보험

> **한눈에** 원화 기준 순수보장성 **90세** 만기 정기보험으로, 10년 경과 후 매년 가입금액의 **10%**씩 사망보험금이 정액 체증합니다. 저해약환급금형이라 3년 이전 해지 시 환급금 **0%**입니다. 환율 변동 없이 원화로 대표 보장을 설계하려는 법인에게 씁니다.
> 내부 참고용. 고객에게는 가입설계서·상품설명서 기준으로 안내.

## 핵심 조건 표
| 항목 | 일반가입형 | 간편가입형 |
|---|---|---|
| 가입나이 | 남 **20~70세** / 여 **22~70세** | **30~75세** |
| 가입한도 | **5천만원~50억원** | **5천만원~30억원** (65세 초과 최대 **20억원**) |
| 보험기간 / 납입 | 90세 / 90세납 월납 | 동일 |
| 사망보험금 | 10년까지 가입금액, 이후 매년 **10%** 정액 체증 | 동일. 단 **2년 미만 재해 외 사망 시 50%** |
| 적용이율 | 10년 이내 연복리 **2.5%**, 이후 **1.0%** | 동일 |
| 저해약 비율 | 3년 이전 **0%** / 3~5년 **50%** / 5년~납입기간 **95%** | 동일 |
| 전환 | 종신전환·신연금전환(가입시점) 특약 자동부가 | 간편가입형 종신전환특약 |
| 플러스보험기간 | 없음 (달러형만) | 없음 |

## 해약환급금 예시 (1억원, 40세, 만원)
| 경과 | 일반 남 납입 / 환급 | 환급률 | 간편 남 환급률 |
|---|---|---|---|
| 1년 | 440 / 0 | 0.0% | 0.0% |
| 3년 | 1,321 / 480 | 36.3% | 36.4% |
| 5년 | 2,202 / 1,782 | **80.9%** | 80.4% |
| 10년 | 4,404 / 3,990 | **90.6%** | 89.8% |
| 20년 | 8,808 / 7,952 | 90.3% | 89.4% |
| 40년 | 17,616 / 13,130 | 74.5% | 74.0% |
| 50년(만기) | 22,020 / 0 | 0.0% | 0.0% |

월보험료 환산: 일반 남 약 **36.7만원**, 간편 남 약 **44만원**

## 이런 고객에게
- 환율 리스크 없이 원화로 대표 보장을 설계하려는 법인
- 고액 보장이 필요한 대표 (일반형 최대 **50억원**)
- **최소 5년 이상** 유지할 납입 여력이 있는 법인

## 설명할 때 꼭 말할 것
- ⚠ 3년 이전 해지 시 환급금 **0%**, 3~5년 **50%**. 예시상 일반 남 3년 시점 **36.3%**
- ⚠ 순수보장성이라 90세 만기 시 환급금 **0**. 환급률은 10~20년 구간이 최고
- ⚠ 달러형보다 적용이율(**2.5% vs 3.75%**)과 예시 환급률이 낮다는 점은 정직하게 비교
- ⚠ 간편형은 2년 미만 재해 외 사망 **50%**, 보험료·가격지수(남 **119.8%**)가 높음

> "대표님, 환율 걱정 없이 원화로 보장을 키워 가는 구조입니다. 5년이 지나면 환급률이 80%대로 회복되니 최소 5년 유지를 전제로 설계하겠습니다."

## 자주 헷갈리는 점
| 헷갈리는 점 | 정리 |
|---|---|
| 간편형 한도는 20억? | 기본 **30억원**, 피보험자 **65세 초과** 시 최대 **20억원** |
| 달러형처럼 플러스보험기간? | 원화형은 없음 |
| 납입기간 경과 후 환급 비율? | 요약서 텍스트에서 확인 안 됨 |
| 3년·5년 예시 비율 그대로? | 3년+1일, 5년+1일 시점 비율 적용값이라 실제는 더 적을 수 있음 |
