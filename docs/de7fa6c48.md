# 가족법인을 통한 자산(토지·건물) 이전 및 소득 분산 (현물출자, 가족법인 설립, 대여·채무면제)


## 한 줄 정의
부모(조부)가 보유한 토지·건물과 자녀의 개인사업을 가족법인 구조로 옮겨, 사업소득의 소득세·4대보험을 줄이고 순이익을 자녀에게 귀속시키며, 부모 자산은 대여·채무면제·현물출자 등으로 법인을 통해 승계하는 장기 컨설팅.

## 대상 업체 신호
- 3대 구조: 토지 보유 할아버지 / 건물+사업장 운영하는 대표(아버지) / 손자·손녀
- 토지 공시지가 11억, 시가 21억 → "감정평가 받아야 된다!!!"
- 아버지가 10년 이내 사망 가능성
- 개인사업자로 소득세·4대보험을 내고 있는 사업장(레저시설), 법인 순이익 2억 6천 수준 검토
- 부모가 돈이 많고 소비가 필요 없는 경우

## 고객 니즈/페인포인트
- 노트의 질문 프레임: "나를 찾아온 사람은 누구인지?? (대표자) / 찾아온 이유는?? (상속으로 진행되는 경우 상속세 준비) / 부모의 태도는?? 어떻게든 가져가라"
- "부모 100을 벌어서 50을 세금 내고 모은 돈은 상속세 내면 25. 자녀에게 25만 넘어감"
- 토지를 개인으로 받으면 상속세 부담

## 해결 구조
1. **1차 미팅 구성:** "1. 토지 20억 증여 vs 가족법인 비교 시간플랜 (법인으로 당연히 하게끔) 2. 대표님 소득세, 4대보험 감소하는 효과 3. 자녀한테 귀속되면서 상속 및 이전효과 4. 토지 법인으로 와서 자녀의 이전효과" / "법률적인 검토: 가족법인 실행하는 거에 있어서 여러가지 상황에 판단" / "컨설팅은 장기적으로 진행되어야 되고, 가족법인 세법검토 매년 검토 필요"
2. **사업장 가족법인 전환:** "가족법인 진행이 되어야 될텐데 향후 대표자 등 출구전략 셋팅 / 급여는 최소화 (타소득합산) / 배당은 자녀와 균등배당 / 퇴직금 경정으로 법인세 절감하면서 준비하자!!!" / "법인만의 비용이 필요해 경정기 무조건"
3. **토지 취득 방식:** "사오는건 완전 잘못: 양도세, 양도자금 상속, 취등록세, 아버지가 쓰고" [해석: 법인이 토지를 매입하면 부모에게 양도세, 양도대금이 다시 상속재산이 됨]
4. **사전증여 합산:** "법인은 사전증여합산 5년" / "배우자쪽으로 상속해서 승계작업을 이어가자 (포괄까지 할건지? 선택하고해야됨)"
5. **비교 케이스:** "감정가액을 최소화 해서 증여를 하는게 맞다고 판단" / 케이스1: 사전증여받는 경우(상속세 8억, 토지가 상승에 대해 설명) / 케이스2: 가족법인 설립(구체적으로 이야기하지 말고)
6. **김시현 세무사 컨셉 이론:**
   - 요청자료: 1. 부모님 재산파악 2. 가족관계(아들의 가족관계) 3. 취득자료
   - 케이스 1번 양도: 양도세, 취득세, 상속세 추가 납부 → 비추천 / 케이스 2번 증여: 증여세, 취등록, 사전증여 10년 합산
   - **현물출자:** "취등록세만 내고 양도소득세 이월과세 / 아버지, 어머니 90% 자녀 10% / 51% 미만은 처분이 가능해... 5년동안만 51%미만 건들고" / 효익: 부모 소득세 약 2억 절감, 법인세는 약 4천만원 예상 / 부동산 주식 변경: "양도소득세 이월과세 (세금이 10억 예상) 일정시간이 지나면 부채로 잡힌다. 80억짜리 건물 10억 부채 순자산가액 70억, 승계 이익효과"
   - **가족법인(자녀별 설립):** "돈이 생기면 현물출자 법인의 주식을 취득 / 80억 빌릴 수 있다(자녀2명, 자녀의자녀 2명) 무이자의대한 혜택을 볼 수 있다 / 80억의 돈을 빌려놨으나 1년에 1억씩 채무면제해서 증여의제이익 활용 / 20년이면 80억 대여금 없앨수 있다 / 본인들 가수금 넣을수 있다"
   - "자녀에게 가족법인을 만들어서 가수금하고 채무면제이익 (증여의제이익효과 활용) / 소득세 절세효과, 승계의 절세효과"
   [현물출자 이월과세 요건(조특법), 지분 처분 제한, 특정법인 증여의제 계산은 노트에 근거 조문이 없음. 일반지식, 확인필요]

## 연계 보험상품 및 연결 논리
- "퇴직금 경정으로 법인세 절감하면서 준비하자", "법인만의 비용이 필요해 경정기 무조건"
- "급여로 받기에는 부담스러우니 퇴직금 모은다고 생각하고 진행하시자 / 퇴직금 노후생활 준비 / 사망보험금 상속감자 컨셉 설명하면서"
- "(대표, 배우자 합산 600) *800부르고" [해석: 월 보험료 제안 규모 메모로 보임, 확인필요]

## AP에서 던질 질문
- 승계 현황 파악: "1. 가족관계 (부모, 배우자, 형제 등 파악) 2. 아버지 나이 등 재산 파악"
- "부모님께서는 이 재산을 어떻게 하고 싶다고 하세요?" (부모의 태도) [구성 예시, p.1 질문 프레임]
- "토지는 언제 얼마에 취득하셨어요?" (취득자료)
- 팁: "승계의 경우에는 대표자의 니즈를 파악해서 그걸 생각해서 대표자가 원하는걸 계속 이야기할 것"

## PC/제안 단계 화법
- "내가 무조건 맞다" [해석: 확신을 갖고 방향을 제시하라는 취지]
- "다음미팅때 방향성 추가설명 / 토지를 어떻게 이전하는 지 향후 설명 / 절세효과 숫자로 보내주겠다"
- "대표님이 앞으로 어떻게 해야될지! 매년 제가 어떻게 관리를 해드릴지 정리해서 오겠다"
- "가족법인 활용도 엄청많다. 가족법인 전문 세무사에게 맡기셔야한다. 장기 컨설팅에 해당된다" / "썰매장(사업장) 기장 제가 하는게 맞다"
- 100-50-25 화법

## 자주 나오는 반론과 대응
- 노트에 명시된 반론 없음. "케이스2 가족법인 설립은 구체적으로 이야기하지 말고" = 1차 미팅에서 구조 디테일을 열지 않는 원칙 (AP 11단계 원칙과 동일).

## 주의사항·리스크
- 감정평가 필요성(공시지가 11억 vs 시가 21억 괴리). 감정가액 최소화 판단.
- 법인 사전증여 합산 5년, 개인 사전증여 10년 합산, 배우자 상속 경유 시 포괄 여부 선택.
- 현물출자 후 지분 처분 제한, 이월과세 양도세가 부채로 잡히는 효과 등은 세법 요건 정밀 검토 필요.
- 변호사 유증 안내 언급: 아버지 10년 내 사망 시 "변호사한테 유증받는방법 안내하겠다".

## 필요 자료 / 협업 자격사
- 요청자료: 사업장 재무제표, 소득세 신고서, 4대보험 체크, 절세금액 정리(소득세, 4대보험 / 대표자 상속세, 자산 자녀이전), 부모님 재산, 가족관계, 취득자료.
- 세무사(가족법인 전문), 감정평가사, 변호사(유증), 법무사(현물출자·설립).
