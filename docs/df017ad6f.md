# 경영인정기보험(경정기)

## 한 줄 정의

계약자·수익자 법인, 피보험자 대표이사, 정기보험(전기납, 90세 만기). (세무 처리는 세무사 검토 사항)

## 대상 업체 신호

- "이익이 나서 법인세 부담이 큰 법인 / 대표 퇴직재원을 미리 만들어야 하는 법인 / 대표 유고 시 회사가 흔들릴 구조인 법인 / 40대 대표. 환급률이 가장 유리하게 나옵니다"
- 주식가치 상승 법인: "기업성장에 따라 주식가치 상승하면 대표자 유고리스크시 남은 상속인 부담. 주식가치 낮추는 목적도 조금 있음". 경정기 월 500 가입 시 주가 하락 그래프를 보여주고 "대표한테 주가 가치 낮추자고 하면서 파는 거"
- 법인전환 직후 "설립 이후 급여 세팅" 시점
- 세무 처리(비용처리·손금·익금 등)는 세무사 검토 사항입니다.

## 고객 니즈

대표 퇴직금 재원 대표 유고 시 회사·가족 유동성 상속세 납부재원(상속감자 연결) 주식가치 관리 달러 분산(달러형). (세무 처리는 세무사 검토 사항)

- 기본(메트 달러경정기 실제 설계서, 35세 남, 월 200.4만원, 가입금액 $333,000 ≈ 4억 5,338만원): 3년 35.92% / 5년 80.73% / 7년 88.04% / **10년 93.29%(정점)** / 20년 90.79% / 30년 90.07% / 50년 52.44%. "적용이율이 10년 이내 3.75%, 10년 초과 1.00%로 바뀌기 때문." 사망보험금 "10년 이후 매년 10%씩 정액 체증". "90세까지 계속 내고, 90세를 넘으면 환급금이 0이 됩니다. 이 점을 반드시 설명해야 합니다."
- 세무 처리(비용처리·손금·익금 등)는 세무사 검토 사항입니다.
- 그래서 3년 전부터 급여를 세팅해 둡니다." (세무 처리는 세무사 검토 사항)
- 상속감자로 상속인에게 이전 가능. (세무 처리는 세무사 검토 사항)
- 납입 출구 기능 4개: "감액완납: 5년 시점에 설정하면 그 이후 한 푼도 안 냅니다. 보장보험금은 낮아지지만 환급금은 그대로 남아 계속 불어납니다." / "종신전환: 7년 이후 종신보험으로 바꿉니다. 납입을 멈추고도 사망보장을 평생 가져갑니다. 퇴직 시점에 맞춰 쓰는 기능" / "연금전환: 7년 이후 계약자적립액을 연금으로" / "보험계약대출: 해지하지 않고 해지환급금에 비례해 자금을 씁니다. 대출금으로 다시 보험료를 내는 경우도 실제로 많습니다." "종신전환: 더 이상 납입 안하고 싶다 + 사망보장 기능 챙기고 싶다 / 감액완납: 더 이상 납입 안하고 싶다 + 사망보장 거의 필요 없다"
- 실무 운용: "실제로는 끝까지 안 냅니다... 5년 감액완납 / 7년 후 종신전환... 10년납까지 가는 경우는 오히려 드뭅니다." "지금 설계서의 환급률표는 전기납을 계속 유지하는 기준입니다. 감액완납·종신전환 이후의 환급률은 별도 설계가 필요합니다." "7년납 / 10년해지가 기본셋팅 95% 환급률, 7년납 / 7년 해지시 90%". 초회보험료 202만9천원(원화 고정납 적용), "7년납 10년 해지시 94.5%", 사망보험금 $281,000.
- 원화 고정납(달러형): 실제 보험료보다 원화로 더 고정 납입, 최소 +10%(예: 200.4만 → 220.5만, 최대 260.6만), 차액이 달러로 적립되어 "해지환급금 상승 효과(사망보험금 x)" / "적립액은 사망보험금에 가산되어 지급". 환급률 약 +1%p, 보장보험금 약 4,170만원 감소. "고객 예산이 월 200만원이면 기본 보험료를 약 182만원으로 낮춰 설계해야 고정납 10%를 붙였을 때 실제 출금이 200만원이 됩니다." "퇴직재원이 목적이면 고정납이 유리하고, 유고 대비가 목적이면 기본을 크게 가는 게 맞습니다. 고객 예산에서 역산해야지, 설계서 숫자를 그대로 쓰면 안 됩니다." "원화고정납이란 10%는 보험가입이 아닌 달러만 모으는 성격, 달러 환율 변화하면 가져다 쓰는거"
- 상품 비교: 일반 40세 1억 10년 환급률 1위 푸본현대 95.8%, 메트 달러 2위 94.9%, 메트 원화 9위 90.6%(보험료 최저 월 36.7만). 간편심사는 보험료 약 20% 높고 환급률 1%p 내외 하락. 70세 이상 전 상품 60%대. 가입한도 상위: KB라이프 999억(원화), 메트 달러 일반 500만달러. (세무 처리는 세무사 검토 사항)
- 신설법인 가입 제한: "법인 전환 시기로 소급해서 개인 사업자의 설립 연도를 따져봤을 때 2년이 초과되면 모든 상품이 다 가입 가능... 금액도 한도가 없어요. 재정만 볼 뿐". 최초 설립 법인은 "메트라이프 경영인 정기보험은 가입이 안 돼요", "KB 경영인 정기보험은 법인의 한도가 199만 원", 한화는 "피보험자당 199만 원"(대표+배우자 각각 가능). [시점 의존 정보, 확인필요]
- 향후: 메트 변액 결합 경정기(MAVERICK) 10/20 출시 예정, 출시 전까지 TheClassic 기준 상담.

## 연계 보험상품과 연결 논리

1. 법인전환 → 인출 3파이프: "법인 전환 이후 대표가 돈을 가져가는 길은 세 가지 파이프밖에 없습니다... 급여 설계 / 배당 정책(연 2천만 원 구간을 '정기 출구 옵션') / 퇴직금 플랜(4대보험료 부과가 없고 퇴직소득세로 나가기 때문에, 큰 돈을 깨끗하게 꺼내는 통로)" → "출구는 재원이 있어야 완성되거든요" → 경정기. "급여셋팅없이 EXIT을 실행하다보면 결국 개인사업자보다 세금을 많이부담"
2. 그래서 저는 퇴직금으로 얘기합니다. 그래서 투 트랙으로 가면 저는 오히려 조금 더 확률이 높아져요." 실제 세팅 예: 월급여 800 + "퇴직금을 300만 원씩 불입을 하자. 적립 기간은 7년... 10년 이후에 퇴직금이 2억 5천씩 세팅"(2인, 달러 경정기) (세무 처리는 세무사 검토 사항)

5. 상속재원: 법인 보험금 → 상속감자 → 상속세 납부. 낼 돈을 만들어 줍니다." (세무 처리는 세무사 검토 사항)
6. 보험료 재원 만들기: 오달연 쿠폰 → 경정기 보험료(7장 참조)
