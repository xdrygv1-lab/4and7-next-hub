기준일 2026-10-04 · 지점 · 체크리스트 + 예시 + 도구 중심

> TL;DR
> 1. AP의 결과물은 계약이 아니라 **다음 약속 + 소개**.
> 2. 제안 전 **선심사**, 고객 화면 숫자는 **실제 가입설계서**.
> 3. 2027년부터 수당은 **분할 지급**. 유지율 = 소득.
> 4. 세무 문구는 정정사항 그대로. "100% 손금", "30% 비용처리" 금지 (세무사 검토 필요).
> 5. 수익 약속 표현 금지.

## 2. 예시로 이해하기

### 예시 1. 같은 1억 보장, 10년 뒤 남는 돈 (40세 남, 일반심사, 비교자료 2026.09)
| 상품 | 월보험료 | 10년 총납입 | 10년 환급금 | 10년 순비용 |
|---|---|---|---|---|
| 푸본현대 MAX경영인정기탑픽Ⅱ | 412,000원 | 4,944만 | 4,736만 | 208만 |
| 메트 TheClassic 달러 | 515,200원 | 6,182만 | 5,867만 | 315만 |
| 메트 TheClassic 원화 | 367,000원 | 4,404만 | 3,990만 | 414만 |

- 포인트: 메트 달러형은 가입금액이 $10만(약 1.4억, 환율 1,400원 가정)이라 다른 1억 상품과 보장금액이 다릅니다. 메트 원화형은 환급률은 하위권이지만 보험료가 가장 낮아 "같은 예산으로 보장금액 최대화" 니즈에 맞습니다.

### 예시 2. 일반 vs 간편 (40세, 메트, 1억)
| 상품 | 일반 월보험료 | 간편 월보험료 | 차이 |
|---|---|---|---|
| TheClassic 달러 | 515,200원 | 623,000원 | +21% |
| TheClassic 원화 | 367,000원 | 440,000원 | +20% |
→ 간편은 약 20% 비싸고, 같은 예산이면 보장금액이 약 17% 줄어듭니다. 간편은 2년 내 질병 사망 시 50% 지급.

### 예시 3. 70세 이상 대표
- 모든 경정기 10년 환급률이 60%대로 떨어집니다. 고령 대표에게는 경정기보다 종신·상속형 검토가 맞습니다. (06 시뮬레이션 결론 4)

### 예시 4. 분급제 숫자 감각 (월보험료 10만원, OR·본인 지급률 적용 전 재원)
| 구분 | 1년차 재원 | 그 뒤 |
|---|---|---|
| 지금 | 1,200% = 120만원 | 없음 |
| 4년 분급 | 1,195% = 119.5만원 | 36개월 분할 |
| 7년 분급 | 1,090% = 109만원 | 72개월 분할 |
- 선지급 한도는 1,150% → 970% (약 16% 축소). 계산기의 "약 37%" 문구는 출처 표기 오류입니다.
- 공식 출처: 외부 비교 데이터 분급제 계산기 v3.1 (05 문서). 감독규정 원문 대조 전이라 [확인필요]. 실제 수령액은 OR과 본인 지급률을 적용해야 합니다.

### 예시 5. 고객에게 쓰는 세무 문구 (복사해서 쓰기, 세무사 검토 필요)
- 경정기: "퇴직 시점이 정해지지 않은 정기보험은 국세청 해석상 보험료를 기간 경과에 따라 손금으로 봅니다(서면-2020-법인-3181 등). 정관에 임원 정년이 있으면 일부는 자산으로 잡힐 수 있고, 해지·감액완납·전환 때는 해약환급금이 전액 익금이 됩니다."
- 원금형 종신(법인): "국세청 해석상 보험료 손금 처리가 가능하다는 해석(사전-2026-법규법인-0062)이 있지만, 해지 시 전액 익금이고 심판례(국심2006서3194)상 자산계상 논리도 있어 처리 방식은 세무사와 결정합니다."

## 3. 금지어 vs 대체 표현

| 쓰지 않는 말 | 대신 이렇게 |
|---|---|
| 100% 손금 / 전액 비용처리 | 국세청 해석상 기간 경과에 따라 손금 (세무사 검토 필요) |
| 30% 비용처리 | (비율 언급 없이) 처리 방식은 세무사와 결정 |
| 전환하면 세금 없이 넘어가요 | 전환 시점에 해약환급금 익금이 발생합니다 |
| 확정 수익 / 무조건 남아요 / 저축이에요 | 보장성 보험입니다. 중도 해지 시 원금 손실이 있을 수 있습니다 |
| 10년 뒤 95% 돌려받아요 (먼저 꺼내기) | 완납·유지 전제. 환급률은 설계서 기준, 해지 전제로 설명하지 않음 |
| 달러라서 안전해요 | 환율이 내리면 원화 기준 손실이 날 수 있습니다 |
| 올해 안에 하셔야 해요 (분급제 때문) | 분급제는 내부 사정. 고객 화법으로 쓰지 않음 |
| 상속세 최고 40% | 현행 최고세율 50% [최신 세법 확인] |

**도구 사용 원칙**
1. 도구 수치는 **내부 검토용**. 고객 자료는 실제 가입설계서.
2. 시뮬레이터의 40·50·60·70세 외 나이는 **추정값**(보간).
3. 고객 실명·주민번호 등 개인정보는 도구에 넣지 않기. "OO산업, 김 대표님" 수준으로 익명화.
