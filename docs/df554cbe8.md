# 참고: 세법 기준과 자료 간 상충 정리

> 컨셉카드 공통 참고. 가족법인·승계 클러스터 다이제스트 0장(공통 설계 논리, 현행 법령 요지, 상충 표시)을 그대로 옮김. 수치·세율은 인용 전 현행 확인 필요.

> "부동산·사업을 직접 넘기지 않고 법인 주식으로 바꿔 단계 승계 → 현물출자로 양도세 이월 → 가족법인이 주식 취득 → 부모(또는 부친) 자금을 무상대여 후 채무면제로 낮은 세율 이전 → 지분 정리 후 초과배당으로 가속 → 잔여 지분도 상속 대비 단계 이전. 모든 단계는 단정적 절세가 아니라 '자료·현행 확인 후 매년 검토하는 도구.'"

- 핵심 프레임: "법인은 절세의 도구가 아니라 구조의 도구", "개인명의는 편하게 진행되지만 결국 가장 비싸게 끝나는 구조"
- 보험 연결 공통 논리: 구조가 돌아가면 법인에 현금이 쌓이거나(임대소득·사업이익) 법인세가 튀어나온다(채무면제이익) → 확정 비용 + 퇴직금 재원 + 유고 시 상속세 재원 = 경영인정기보험(경정기). 고령이면 제로백 종신, 부모 현금이 크면 오달연(저축성 달러연금, "금융빌딩")으로 보험료 재원.
- 톤 규칙(전 자료 공통): "세금이 없어지는 구조"가 아니라 "낮은 세율로 나누어 이전하는, 매년 검토가 필요한 도구". "보험으로 절세됩니다" 금지.

| 지방세법 §7⑤ | 과점주주 간주취득세. 설립 시 발행주식 취득은 제외. 가족 특수관계 그룹 내부 이전은 그룹비율 불변 시 추가 없음이 원칙 |
| 법인세법 §60의2 | 성실신고확인 대상 법인(①소규모 임대법인: 지배주주+특수관계 50% 초과, 5인 미만, 임대·이자·배당 매출 50% 이상 ②성실신고 개인사업자 전환 후 3년 내) |
| 상증법 §45의5 | 특정법인(지배주주등 주식보유비율 30% 이상)과의 거래를 통한 이익의 증여의제. 증여의제이익이 주주별 1억원 이상인 경우만 과세(시행령 §34의5⑤). 2025년 개정으로 자본거래(3의2호, 불균등 감자·초과배당 등) 유형 신설 |

| 상증법 §41의2 | 초과배당 증여의제. 2021.12.21 개정으로 소득세 정산 후 증여세까지 정산하는 구조 → "1억 한도 비과세" 단순설명 불가 |
| 상증법 §13 | 사전증여 합산: 상속인 10년, 상속인 외(법인·며느리·손주 등) 5년 |
| 상증법 §43② | 1년 내 동일인·동일 거래 이익 합산해 1억 판단 |
| 세율(2026) | 상속·증여세 최고 50% 유지(40% 인하안 부결), 유산취득세 미시행, 자녀공제 1인 5천만원. 법인세 2026.1.1부터 전 구간 +1%p(2억 이하 10%, 2억~200억 20%), 부동산임대 주업 소규모 법인은 200억 이하 20% 단일 |

[충돌] 현물출자 사후관리 처분 기준: 단장 교육 녹취(26.06.19)는 "51% 미만은 처분이 가능"이라 말하지만, 통합스크립트는 "사후관리 '50%'가 법문(조특§32⑤). '51%' 아님"으로 정정. 실무 안전선은 부모 취득주식 90% 기준 45%p 중 44%p.

[구버전 의심] 기업의별 부동산 현물출자 강의(2022)는 현물출자 취득세 "75% 감면, 감면분 20% 농특세"로 설명. 현행 임대업은 지특법 §57의2④로 감면 배제(자료 다수). 업종별로 구분해 쓸 것.
