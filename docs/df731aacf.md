# 약관정리_TheClassic원화경영인정기 (메트라이프)

> 이 문서는 주계약(보통약관) 본문에 있는 운용 조건만 정리했습니다. 상품요약서 정리와 겹치는 내용은 줄이고 보완 위주로 적었습니다.
> 조항 번호는 원화 일반가입형 약관 기준입니다. 약관에 없는 내용은 "약관에 없음"으로 표기했습니다.
> 중요: 종신전환특약, 신연금전환특약_(가입시점) 등 특약은 약관 파일의 특약 색인에 "별도약관"으로만 표시되어 있고, 본문은 이 파일에 들어 있지 않습니다. 전환 조건은 해당 특약 약관을 따로 받아 확인해야 합니다.

## 4. 조기계약전환, 기타 전환 제도

### 4-1. 조기 계약전환 옵션 (제44조)

| 항목 | 약관 내용 | 조항 |
|---|---|---|
| 신청 요건 | 보험료를 납입한 기간이 3년 이상 경과한 계약 (보험료를 36회 이상 납입한 계약) | 제44조 ① |
| 절차 | 계약자가 신청하고 회사 승낙을 받아 회사가 정한 전환상품으로 전환 | 제44조 ① |
| 전환 처리 | 이 계약의 잔여보험료를 납입하지 않고 해지한 후 전환상품으로 전환 | 제44조 ③ |
| 전환 후 적용 약관 | 이 계약은 해지되고 전환된 상품의 약관 및 기초서류를 따름 | 제44조 ④ |
| 불이익 | 해약환급금이 가입 시 안내보다 적어질 수 있음. 회사가 정한 최저가입금액 기준 미달 시 추가 납입금 발생 가능 | 제44조 ⑤ |
| 전환상품 종류 | "회사가 정한 전환상품"으로만 기재. 구체 상품명은 약관에 없음 | 제44조 ① |

전환 사유와 구비서류 (계약자 또는 피보험자 기준, 제44조 ②):

| 사유 | 구비서류 |
|---|---|
| 1. 영위하는 사업장의 폐업 | 폐업사실증명원 |
| 2. 3개월 이상의 입원치료 또는 요양을 요하는 상해·질병의 발생 | 입·퇴원확인서 |
| 3. 계약체결 당시 대표이사였던 직위가 전환신청 당시 변경된 경우 | 법인등기부등본 |
| 4. 계약체결 당시 최대주주였던 직위가 전환신청 당시 변경된 경우 | 주주명부, 주식 등 변동상황명세서 |

## 8. 계약자·수익자 변경

| 항목 | 약관 내용 | 조항 |
|---|---|---|
| 계약자 변경 | 회사의 승낙을 얻어 변경 가능 | 제20조 ①3호 |
| 변경 후 조치 | 회사는 변경된 계약자에게 보험증권 및 약관 교부, 요청 시 약관 중요내용 설명 | 제20조 ⑥ |
| 수익자 변경 | 회사 승낙 불필요. 다만 변경된 수익자가 회사에 대항하려면 계약자가 회사에 통지해야 함. 통지 전 회사가 변경 전 수익자에게 지급하면 변경된 수익자에게는 지급하지 않음 | 제20조 ② |
| 피보험자 동의 | 계약자와 피보험자가 다를 때 수익자 변경은 지급사유 발생 전 피보험자의 서면(전자서명 전자문서 포함) 동의 필요 | 제20조 ⑦ |
| 수익자 미지정 시 | 피보험자의 법정상속인 | 제11조 |
| 계약자 2명 이상 | 대표자 1명 지정, 계약자 책임은 연대 | 제12조 |
| 특별부활 시 명의변경 | 강제집행, 담보권실행, 국세 및 지방세 체납처분으로 해지된 경우, 해지 당시 수익자가 계약자 동의를 얻어 채권자 지급액을 회사에 내고 계약자 명의를 수익자로 변경해 특별부활 청약 가능. 회사는 해지일부터 7일 이내 통지, 수익자는 통지받은 날부터 15일 이내 이행. 회사는 승낙 | 제28조 |
| 법인 → 개인(대표) 명의변경 특칙 | 약관에 없음. 법인 계약자를 대표 개인으로 바꾸는 별도 요건·제한·절차 조항이 없고, 일반 계약자 변경(제20조 ①3호, 회사 승낙)으로만 규정 | 해당 없음 |
| 피보험자 서면동의 철회 | 서면동의한 피보험자는 계약 유지 기간 중 언제든지 장래를 향해 철회 가능. 철회로 해지되면 해약환급금을 계약자에게 지급 | 제29조 ② |

## 9. 해지·해약환급금, 저해약환급금 적용 규정

| 항목 | 약관 내용 | 조항 |
|---|---|---|
| 임의해지 | 계약 소멸 전 언제든지 해지 가능, 제32조 ① 해약환급금 지급 | 제29조 ① |
| 계산 기준 | 보험료 및 해약환급금 산출방법서에 따름 | 제32조 ① |
| 저해약 비율 | 3년 이전 0% / 3년~5년 이전 50% / 5년~"납입기간" 이전 95% (경과월수 60개월이 지난 후 도래하는 월계약해당일부터 납입기간까지) | 제32조 ① 유의사항 다 |
| 비교 기준 | 유해약환급금형 해약환급금은 산출방법서 방법으로 해지율을 적용하지 않고 계산 | 제32조 ① 유의사항 나 |
| 납입기간 경과 후 비율 | 원화 약관 표에는 해당 행이 없음 (달러 약관은 100% 명시) | 제32조 ① |
| 지급 기한 | 청구 접수일부터 3영업일 이내 | 제32조 ② |
| 경과기간별 표 | 회사가 계약자에게 제공 | 제32조 ③ |
| 위법계약 해지 | 금융소비자보호법 제47조에 따라 계약체결일부터 5년 이내, 위반사항을 안 날부터 1년 이내 요구 가능. 이 경우 해지 당시 계약자적립액 반환 | 제29조의2, 제32조 ④ |
| 중대사유 해지 | 고의 사고 유발, 청구서류 위·변조 시 회사가 안 날부터 1개월 이내 해지 가능, 해약환급금 지급 | 제30조 |
| 회사 파산 | 계약자 해지 가능. 해지하지 않으면 파산선고 후 3개월 지나면 효력 상실 | 제31조 |
| 해약환급금 지연이자 | 지급사유 발생 다음날~청구일: 1년 이내 평균공시이율의 50%, 1년 초과 평균공시이율의 40%. 청구일 다음날~지급일: 보험계약대출이율 | 별표2 |
| 감액 시 | 감액 부분은 해지로 보아 해약환급금 지급 | 제20조 ③ |

## 14. 실무 체크포인트 (약관 근거)

1. 감액완납은 계약일로부터 5년 경과 후에만 가능(제20조 ⑤). 5년 이전에 자금 사정이 나빠지면 감액(감액분 해지 처리, 저해약 비율 적용)이나 해지밖에 없고 자동대출납입도 적용되지 않으므로(제25조), 납입 여력을 최소 5년 기준으로 점검.
2. 보험계약대출은 계약일부터 10년이 지나면 신청 불가, 피보험자 75세 초과도 불가(제33조 ⑤). 3년 이전은 해약환급금 비율 0%라 대출 여력도 제한. 법인 유동성 용도로 대출을 안내할 때 이 기간 제한을 반드시 설명.
3. 대표이사 직위 변경, 최대주주 지위 변경, 폐업, 3개월 이상 입원·요양 시 36회 납입 후 조기 계약전환 신청 가능(제44조). 다만 해약환급금 감소와 추가 납입 가능성이 있고, 전환상품은 약관에 특정되어 있지 않으므로 신청 당시 회사 기준 확인.
4. 법인에서 대표 개인으로 계약자 변경은 일반 계약자 변경(제20조 ①3호)으로 회사 승낙 필요. 약관상 별도 제한은 없음. 변경 시점 평가액과 과세 문제는 세법 확인필요.
5. 수익자 변경은 승낙 없이 가능하지만 회사 통지 전에는 대항 불가(제20조 ②). 계약자(법인)와 피보험자(대표)가 다르면 피보험자 서면동의 필수(제20조 ⑦). 계약자·수익자 변경 서류를 함께 처리.
6. 연체 시 납입최고 14일 이상 후 다음 날 해지(제26조), 해지 시 대출 원리금 즉시 차감(제33조 ③). 부활은 3년 이내 가능하나 고지의무가 다시 적용되고 자살 면책 2년이 부활 청약일부터 다시 시작(제27조, 제5조).
7. 종신전환·연금전환은 주계약 약관에 조건이 없는 별도 특약 사항. "나중에 종신으로 바꾸면 된다"고 설명하기 전에 종신전환특약·신연금전환특약 약관으로 시점·요건 확인. 전환 시 과세 여부는 세법 확인필요.
