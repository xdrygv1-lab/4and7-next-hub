# 약관 정리: TheClassic 원화 경영인정기보험

> **한눈에** 메트라이프 TheClassic 경영인정기보험(원화) 주계약 약관에서 운용 조건만 뽑았습니다. 법인 대표에게 감액완납, 조기 전환, 대출, 명의변경을 설명할 때 씁니다. 종신·연금 전환 조건은 주계약 약관에 없어 별도 특약약관 확인이 필요합니다.
> 내부 참고용. 고객에게는 가입설계서·상품설명서 기준으로 안내.

## 핵심 조건 표
| 항목 | 약관 내용 | 조항 |
|---|---|---|
| 사망보험금 | 10년 경과 계약해당일 전일까지 가입금액, 이후 매년 가입금액의 **10%**씩 정액 체증 | 별표1 |
| 감액완납 | 계약일부터 **5년** 경과 후, 회사 승낙 | 제20조 ⑤ |
| 저해약 비율 | 3년 이전 **0%** / 3~5년 **50%** / 5년~납입기간 **95%** | 제32조 ① |
| 조기 계약전환 | 보험료 **36회** 이상 + 4가지 사유 시 회사가 정한 전환상품으로 | 제44조 |
| 보험계약대출 | 해약환급금 범위. 전기납 + 계약일부터 **10년** 미경과 + 피보험자 **75세** 이하 | 제33조 |
| 중도인출·추가납입 | 약관에 없음 | |
| 플러스보험기간 | 없음 (달러형만 있음) | |
| 자동대출납입 | 적용하지 않음 | 제25조 |
| 종신·연금 전환 | 주계약 약관에 없음 (별도 특약약관 확인 필요) | |

조기 계약전환 사유와 서류: 폐업(폐업사실증명원), 3개월 이상 입원·요양(입·퇴원확인서), 대표이사 직위 변경(법인등기부등본), 최대주주 지위 변경(주주명부, 주식 등 변동상황명세서)

## 이런 고객에게
- 원화로 대표 유고 대비 보장을 마련하고 환율 변동을 피하려는 법인
- 퇴임·지분 변동 가능성이 있어 중간 전환 여지가 필요한 대표
- 최소 **5년** 이상 납입 여력이 확실한 법인

## 설명할 때 꼭 말할 것
- ⚠ 5년 이전 자금 사정이 나빠지면 감액(감액분 해지 처리)이나 해지밖에 없고 자동대출납입도 안 됩니다. 납입 여력을 최소 5년 기준으로 점검
- ⚠ 3년 이전은 해약환급금 **0%**라 대출 여력도 없습니다
- ⚠ 대출은 계약일부터 10년이 지나면 불가. 법인 유동성 용도로 안내할 때 기간 제한 설명
- ⚠ 조기 계약전환 시 해약환급금이 줄고 추가 납입이 생길 수 있음
- ⚠ 대표(피보험자)는 서면동의를 언제든 철회할 수 있고, 철회 시 계약이 해지됩니다

> "대표님, 처음 3년은 해지하시면 돌려받는 돈이 없는 구조라, 최소 5년은 납입 가능한 금액으로 정하시는 게 안전합니다."

## 자주 헷갈리는 점
| 헷갈리는 점 | 정리 |
|---|---|
| "나중에 종신으로 바꾸면 된다"? | 종신전환은 별도 특약 사항. 특약 약관으로 시점·요건 먼저 확인 |
| 법인에서 대표 개인으로 명의변경? | 전용 조항 없음. 일반 계약자 변경(회사 승낙). 세무 처리는 세무사 검토 사항 |
| 수익자 변경도 승낙 필요? | 불필요. 단 회사 통지 전에는 대항 불가, 피보험자 서면동의 필수 |
| 달러형과 조건이 같다? | 감액완납·계약자 변경·납입최고·부활·면책은 같음. 원화형은 플러스보험기간·추가납입·중도인출 없음 |
| 간편형 차이? | 2년 내 재해 외 원인 시 **50%** 지급, 3개월 내 일반심사 가입 시 무효 가능 |

## 연체·해지 때 알아둘 것
- 납입최고 **14일** 이상, 끝난 다음 날 해지. 대출 원리금은 즉시 차감
- 부활은 해지일부터 **3년** 이내. 고지의무 다시 적용, 자살 면책 **2년**이 부활 청약일부터 다시 시작
- 위법계약 해지는 체결일부터 **5년**, 안 날부터 **1년** 이내. 계약자적립액 반환
- 해약환급금·보험금 청구권 소멸시효 **3년**

## 꼭 확인할 것
- [ ] 종신전환특약·신연금전환특약 약관을 별도 확보해 시점·요건 확인
- [ ] 조기 계약전환 시 "회사가 정한 전환상품"의 상품명·조건
- [ ] 감액완납 후 체증 유지 여부 (약관에 없음, 확인 필요)
- [ ] 납입기간 경과 후 저해약 비율 (원화 약관 표에 없음, 확인 필요)
- [ ] 명의변경·전환 시 세무 처리는 세무사 검토 사항
